# PLAYTEST — 사용자 테스트 플레이 체크리스트

> 작업마다 "직접 해 보고 확인할 것". **위가 최신**, 새 작업이 끝나면 맨 위에 절을 추가한다(CLAUDE.md 세션 규칙 4). 최근 여섯 절만 둔다 — 그 전 절은 `docs/archive/PLAYTEST_OLD.md`(맨 위가 최신).
> 키(`data/input.json`): 살피기 **Enter** · 대기 Space · 휴식 Z · **메뉴 Tab**(아군 · 캐릭터 · 소지품, 아이템은 여기서만) · 일시정지 Esc/P · 디버그 F1 · 고르기 **Enter** · 취소 **Esc**(Backspace는 전투 행동창 뒤로만) · 커서 W/S/A/D. 마우스·터치는 쓰지 않는다.
> 옛 절은 그날 기준이다 — 지금 규칙은 `docs/CANON.md`.

| 9 | 어느 건물이든 층을 오가고 나오기 | 행동력은 나올 때 1만 준다 |

### 라비기온 7구역 · 시설 여덟 곳 실내 방 (2026-10-31)

| # | 하는 것 | 보여야 하는 것 |
|---|---|---|
| 1 | 새 게임 → 도시 | "라프도니아 · 라비기온 7구역", 거리는 꽃상자가 달린 7구역 건물. 거래소는 없고, 오른쪽 끝에서 D를 더 눌러도 아무 일 없다 |
| 2 | 시설마다 들어가 본다(행동력이 모자라면 F1 디버그로) | 모두 위에서 보는 방 — 길드(게시판·접수원) · 여관(난로·계산대·계단) · 신전(색유리·제단·긴 의자) · 상점(선반·계산대) · 대장간(화덕·모루) · 은행(금고 문·창살 창구) · 훈련장(모래·허수아비) |
| 3 | 여관 주인 앞에서 위를 보고 Enter | 작은 선택 창 — 요기 · 식사(값). 고르면 요리 그림 + 대화창, 다 넘기면 방에 그대로 |
| 4 | 여관 계단 앞에서 Enter | 휴식. 그 뒤 다른 자리는 "오늘은 이만하면 됐다" |
| 5 | 상점 계산대 앞 Enter → [구매] → 하나 산다 → Esc | 오른쪽 아래 창구 카드에서 산다. Esc는 창구만 닫고 방에 남는다. 한 번 더 Esc = 거리로 |
| 6 | 은행 왼쪽 창구(맡기기·찾기) → 나가기 → 오른쪽 창구(세금) | 창구를 쓴 뒤에도 세금 창구를 쓸 수 있다(창구는 방문 활동에 세지 않는다) |
| 7 | 신전 신관 앞 Enter | 정수 제거 창구. 봉헌 촛대 앞은 봉사활동 |
| 8 | 훈련장 허수아비 앞 Enter | 훈련. 교관은 '교관 특강'·'대련' 순에만 말을 건다 |

### 도시 구역 하나 · 거래소는 따로 (2026-10-31)

| # | 하는 것 | 보여야 하는 것 |
|---|---|---|
| 1 | 새 게임 → 도시 | 왼쪽 위 "라프도니아 · 라비기온", 거리는 밝은 사암·푸른 지붕 건물. 예전 뒷골목보다 밝다 |
| 2 | A/D로 거리를 끝까지 넘겨 본다 | 길드 · 여관 · 도서관 · 신전 · 상점 · 대장간 · 은행 · 훈련장 — 거래소 건물은 없고 상점 바로 옆이 대장간 |
| 3 | 오른쪽 끝(훈련장)에서 D를 한 번 더 | "어디로 갈까" 창 — 알미너스 중앙 거래소(컴멜비 5구역) · 그만둔다. 이사 창은 없다 |
| 4 | 거래소를 고른다 → 안에서 Esc | 거래소 안(팔기만). 나오면 거리, 행동력 1 줄어든다 |
| 5 | 여관에 들어간다 | 휴식·요기·식사·든든한 식사가 처음부터 있다(특식은 여관 등롱이 켜진 '여관 특식' 순에만). 실내 그림이 예전보다 밝다 |
| 6 | 상점 [구매]·대장간 [구매] | 상점에 중급·상급 포션·랜턴까지, 대장간에 라이티늄 등 위 소재 장비까지(값이 비싸다) |
| 7 | 도서관 방 | 예전보다 조금 밝다. 책장마다 처음부터 읽을 책이 있다 |

### 도서관 실내 방 · 행동력은 나올 때 (2026-10-31)

| # | 하는 것 | 보여야 하는 것 |
|---|---|---|
| 1 | 새 게임 → 거리에서 도서관에 Enter | 위에서 보는 열람실(뒷벽 책장 여섯·가운데 창·사서 책상·탁자 넷). 달력 카드의 행동력은 아직 3 |
| 2 | W/A/S/D로 걸어 다닌다 | 탐험처럼 걷고, 벽·책장·탁자·책상에 막힌다. 탁자 뒤로 가면 탁자에 몸이 가린다 |
| 3 | 책장 앞에서 위(W)를 보고 선다 | 책장 위에 분야 이름판(미궁에 관하여 …). 등지면 사라진다 |
| 4 | Enter | 펼친 책 그림 + 대화창에 책 글(한 문장씩). 다 넘기면 그림이 걷히고 방에 그대로 선다 |
| 5 | 다른 책장 앞에 서고 Enter | 이름판에 "오늘은 이만하면 됐다", Enter해도 같은 줄만(한 방문에 하나 — 임시값) |
| 6 | 사서 책상 앞(아래쪽)에서 위를 보고 Enter | 고서 해독 — 네크로노미콘이 없으면 "필요한 물건이 없다." |
| 7 | 아래 가운데 문으로 걸어 나간다(또는 Esc) | 거리로. 그때 행동력 3 → 2 |
| 8 | 여관에 들어가 아무것도 안 하고 나가기 | 들어갈 때는 그대로, 나오면 1 줄어든다(모든 시설 같다) |
| 9 | 순이 바뀌어 도서관 등롱이 켜졌을 때(희귀서 입고) 들어간다 | 오른쪽에 쇠사슬 책을 얹은 독서대가 서 있고, 바라보면 "희귀서 열람" |
