### 키 정리 — 살피기 Enter · Backspace는 전투 행동창만 (2026-10-30)

| # | 하는 것 | 보여야 하는 것 |
|---|---|---|
| 1 | 미궁에서 살필 것(동굴 요소·놓인 물건) 옆에 서서 F를 누른다 | 아무 일도 없다. 아래 안내는 "Enter 살피기 — …", Enter로 살핀다 |
| 2 | 맑은 샘처럼 행동이 여럿인 곳에서 Enter → 선택 창이 뜨면 Backspace, 다음엔 Esc | Backspace는 아무 일도 없고, Esc로 창이 닫힌다 |
| 3 | Tab 메뉴에서 물건을 '옮긴다'로 집은 채 Esc, 다시 Esc | 처음 Esc는 옮기기를 그만두고(메뉴는 그대로), 두 번째 Esc는 메뉴를 닫는다. Backspace는 아무 일도 없다 |
| 4 | 도감(B)에서 Enter로 오른쪽 → Esc | 왼쪽 목록으로, 한 번 더 Esc면 닫힌다 |
| 5 | 전투에서 스킬 → 목록에서 Backspace, 아이템 → 대상 고르기에서 Backspace | 명령 칸(공격·방어·스킬·아이템)으로 돌아온다. 같은 자리에서 Esc는 뒤로 가지 않는다 |
| 6 | 전투가 끝나고 정수 "누가 받을까?"에서 Esc | 앞 질문("획득할까?")으로 |
