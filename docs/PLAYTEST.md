### 라비기온 7구역 · 시설 여덟 곳 실내 방 (2026-10-31)

| # | 하는 것 | 보여야 하는 것 |
|---|---|---|
| 1 | 새 게임 → 도시 | "라프도니아 · 라비기온 7구역", 거리는 꽃상자가 달린 7구역 건물. 거래소는 없고, 오른쪽 끝에서 D를 더 눌러도 아무 일 없다 |
| 2 | 시설마다 들어가 본다(행동력이 모자라면 F1 디버그로) | 모두 위에서 보는 방 — 길드(게시판·접수원) · 여관(난로·계산대·계단) · 신전(색유리·제단·긴 의자) · 상점(선반·계산대) · 대장간(화덕·모루) · 은행(금고 문·창살 창구) · 훈련장(모래·허수아비) |
| 3 | 여관 주인 앞에서 위를 보고 Enter | 작은 선택 창 — 요기 · 식사(값). 고르면 요리 그림 + 대화창, 다 넘기면 방에 그대로 |
| 4 | 여관 계단 앞에서 Enter | 휴식. 그 뒤 다른 자리는 "오늘은 이만하면 됐다" |
| 5 | 상점 계산대 앞 Enter → [구매] → 하나 산다 → Esc | 오른쪽 아래 창구 카드에서 산다. Esc는 창구만 닫고 방에 남는다. 한 번 더 Esc = 거리로 |
| 6 | 은행 왼쪽 창구(맡기기·찾기) → 나가기 → 오른쪽 창구(세금) | 창구를 쓴 뒤에도 세금 창구를 쓸 수 있다(창구는 방문 활동에 세지 않는다) |
| 7 | 신전 신관 앞 Enter | 정수 제거 창구. 봉헌 촛대 앞은 봉사활동 |
| 8 | 훈련장 허수아비 앞 Enter | 훈련. 교관은 '교관 특강'·'대련' 순에만 말을 건다 |
