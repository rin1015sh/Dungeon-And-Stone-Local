# PLAYTEST — 사용자 테스트 플레이 체크리스트

> 작업마다 "직접 해 보고 확인할 것". **위가 최신**, 새 작업이 끝나면 맨 위에 절을 추가한다(CLAUDE.md 세션 규칙 4). 최근 여섯 절만 둔다 — 그 전 절은 `docs/archive/PLAYTEST_OLD.md`(맨 위가 최신).
> 키(`data/input.json`): 살피기 **Enter** · 대기 Space · 휴식 Z · **메뉴 Tab**(아군 · 캐릭터 · 소지품, 아이템은 여기서만) · 일시정지 Esc/P · 디버그 F1 · 고르기 **Enter** · 취소 **Esc**(Backspace는 전투 행동창 뒤로만) · 커서 W/S/A/D. 마우스·터치는 쓰지 않는다.
> 옛 절은 그날 기준이다 — 지금 규칙은 `docs/CANON.md`.

### 도서관 실내 방 · 행동력은 나올 때 (2026-10-31)

| # | 하는 것 | 보여야 하는 것 |
|---|---|---|
| 1 | 새 게임 → 거리에서 도서관에 Enter | 위에서 보는 열람실(뒷벽 책장 여섯·가운데 창·사서 책상·탁자 넷). 달력 카드의 행동력은 아직 3 |
| 2 | W/A/S/D로 걸어 다닌다 | 탐험처럼 걷고, 벽·책장·탁자·책상에 막힌다. 탁자 뒤로 가면 탁자에 몸이 가린다 |
| 3 | 책장 앞에서 위(W)를 보고 선다 | 책장 위에 분야 이름판(미궁에 관하여 …). 등지면 사라진다 |
| 4 | Enter | 펼친 책 그림 + 대화창에 책 글(한 문장씩). 다 넘기면 그림이 걷히고 방에 그대로 선다 |
| 5 | 다른 책장 앞에 서고 Enter | 이름판에 "오늘은 이만하면 됐다", Enter해도 같은 줄만(한 방문에 하나 — 임시값) |
| 6 | 사서 책상 앞(아래쪽)에서 위를 보고 Enter | 고서 해독 — 네크로노미콘이 없으면 "필요한 물건이 없다." |
| 7 | 아래 가운데 문으로 걸어 나간다(또는 Esc) | 거리로. 그때 행동력 3 → 2 |
| 8 | 여관에 들어가 아무것도 안 하고 나가기 | 들어갈 때는 그대로, 나오면 1 줄어든다(모든 시설 같다) |
| 9 | 순이 바뀌어 도서관 등롱이 켜졌을 때(희귀서 입고) 들어간다 | 오른쪽에 쇠사슬 책을 얹은 독서대가 서 있고, 바라보면 "희귀서 열람" |

### 균열 아이템 — 스탯 영약 반출 · 전투 도구 하나만 (2026-10-30)

| # | 하는 것 | 보여야 하는 것 |
|---|---|---|
| 1 | 디버그로 균열을 열고 히든 피스 스탯 영약(예: 강철의 묘 1챕터 성유)을 얻은 채 균열을 나온다 | 가방에 그대로 남는다. 미궁·도시에서 Tab 메뉴로 쓸 수 있다 |
| 2 | 언데드 둘 이상과 싸우며 아이템 → 성수 병 | 적 고르기가 열린다. 언데드가 아닌 적은 흐리고 "듣지 않는다" |
| 3 | 데드맨 하나를 골라 쓴다 | 그 데드맨만 맞는다(다른 언데드는 그대로) |
| 4 | 고르기 화면에서 Backspace 두 번 | 아이템 목록 → 명령 칸(커서는 아이템) |

### 키 정리 — 살피기 Enter · Backspace는 전투 행동창만 (2026-10-30)

| # | 하는 것 | 보여야 하는 것 |
|---|---|---|
| 1 | 미궁에서 살필 것(동굴 요소·놓인 물건) 옆에 서서 F를 누른다 | 아무 일도 없다. 아래 안내는 "Enter 살피기 — …", Enter로 살핀다 |
| 2 | 맑은 샘처럼 행동이 여럿인 곳에서 Enter → 선택 창이 뜨면 Backspace, 다음엔 Esc | Backspace는 아무 일도 없고, Esc로 창이 닫힌다 |
| 3 | Tab 메뉴에서 물건을 '옮긴다'로 집은 채 Esc, 다시 Esc | 처음 Esc는 옮기기를 그만두고(메뉴는 그대로), 두 번째 Esc는 메뉴를 닫는다. Backspace는 아무 일도 없다 |
| 4 | 도감(B)에서 Enter로 오른쪽 → Esc | 왼쪽 목록으로, 한 번 더 Esc면 닫힌다 |
| 5 | 전투에서 스킬 → 목록에서 Backspace, 아이템 → 대상 고르기에서 Backspace | 명령 칸(공격·방어·스킬·아이템)으로 돌아온다. 같은 자리에서 Esc는 뒤로 가지 않는다 |
| 6 | 전투가 끝나고 정수 "누가 받을까?"에서 Esc | 앞 질문("획득할까?")으로 |

### 새 종족 — 엘프 · 드워프 · 여우 수인 (2026-10-30)

| # | 하는 것 | 보여야 하는 것 |
|---|---|---|
| 1 | 새 게임 → 캐릭터 만들기에서 종족을 넘겨 본다 | 인간·바바리안·엘프·드워프·수인 다섯 — 능력치 범위가 종족마다 다르다(임시값) |
| 2 | 엘프로 시작해 도시 → 미궁에 들어간다 | 맵에 녹색 겉옷·긴 검은 머리·뾰족한 귀의 엘프가 걷는다(4방향) |
| 3 | 드워프로 시작해 미궁 | 작은 키·뿔 투구(이마까지 덮음)·땋은 수염 — 인간보다 작다 |
| 4 | 수인으로 시작해 미궁 | 여우 귀·꼬리·붉은 목도리, 옆으로 걸을 때 꼬리가 보인다 |
| 5 | 전투에 들어가 공격·스킬·방어·피격·쓰러짐 | 뒷모습 동작이 인간과 같이 나온다 · 팔을 휘둘러도 소매 사이로 살이 비치지 않는다 |
| 6 | 연말 세금 | 이종족(엘프·드워프·수인)은 인간보다 세금이 많다(임시값 — 인간만 0.3배) |
