# PLAYTEST — 사용자 테스트 플레이 체크리스트

> 작업(마일스톤)마다 "직접 해 보고 확인할 것"을 모은다. **위가 최신**이다. 새 작업이 끝나면 맨 위에 절을 하나 추가한다(CLAUDE.md 세션 규칙 4).
> 옛 절의 키·화면 설명은 그때 기준이다 — 지금 조작은 `docs/CANON.md` §7(키보드만, Tab 메뉴, 살피기 F/Enter, 고르기 Enter, 취소 Backspace).

## 체크리스트

> 키(2026-10-19 기준, `data/input.json`): 살피기 **F**(또는 Enter) · 대기 Space · 휴식 Z · **메뉴 Tab**(소지품·캐릭터·도감 한 화면 — 아이템은 여기서만 쓴다) · 일시정지 Esc/P · 디버그 F1 ·
> 고르기 **Enter** · 취소 **Backspace** · 커서 W/S/A/D. **마우스·터치는 쓰지 않는다**(2026-10-19). 아래 체크리스트는 위가 최신이고, 오래된 표는 **그날 기준**이라 지금과 다를 수 있다
> (예: 전투 카드·"아이템…"·흡수 버튼·임시 입장 버튼·식사 소문·247×247 지도·I/C/B 창·마우스 클릭·끌어놓기·툴팁·단축칸 1~0·횃불 T·식사 E는 지금 없다 — 정본은 `docs/CANON.md`).
