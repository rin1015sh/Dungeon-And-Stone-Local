### 전투 아래 창 · 무대에서 대상 고르기 (2026-11-02)

| # | 하는 것 | 보여야 하는 것 |
|---|---|---|
| 1 | 전투를 시작하고 적 차례를 본다 | 왼쪽 명령 칸(공격·스킬·방어·아이템)이 숨어 있다 — 내 차례(행동 정하기)에만 나온다. 파티 창은 자리에서 움직이지 않는다 |
| 2 | 내 차례 | 내 줄이 뼈빛 띠로 빛난다 · 동료 행동을 정할 때는 그 동료 줄이 빛난다 |
| 3 | 민첩이 높아 연달아 차례가 온다 | 이름 왼쪽에 "추가 턴" 작은 창 — 이름·삼각형이 밀리거나 겹치지 않는다 |
| 4 | 행동을 정한 뒤 파티 창 | "공격 → 고블린 A" 같은 글이 없다 |
| 5 | 공격 → Enter | 아래 창 목록 없이 무대의 적이 하얗게 빛나고 위쪽에 이름만 든 작은 창 · A/D로 다른 적(왼쪽·오른쪽) · Enter로 친다 · Backspace로 명령 칸 |
| 6 | 적이 앞뒤 두 줄로 선 전투(균열 무리 — 핏빛성채·빙하굴 연전 등)에서 공격 → W / S | W = 뒷줄 적(가로로 가까운 적), S = 다시 앞줄 · A/D는 같은 줄 안에서만 옮긴다 · 처음 커서는 앞줄 가운데 |
| 6b | (부위 약점 없앰 — C21) 키르뒤·캠보르미어·시체골렘·스켈레톤 | "약점 노리기"가 없다 · 위쪽 창에 "[머리]" 같은 부위가 안 뜬다 · 키르뒤·캠보르미어는 재생을 멈출 길이 없어졌다 — 너무 질기지 않은지 |
| 7 | 스킬 → 아군에게 거는 스킬 | 파티 창 줄에 테두리가 옮겨 다닌다(W/S) |
| 8 | 조사 | 무대의 앞줄 적부터 고른다(앞줄에서 S = 아군) |
| 9 | 균열 화약 주머니 같은 하나만 치는 아이템 | 듣지 않는 적에 커서가 가면 위쪽 창이 흐리게 "이름 · 듣지 않는다", Enter가 먹지 않는다 |
### 기세(옛 Rev Up) — 전투 자원 · 같은 적 무리 (2026-11-02)

| # | 하는 것 | 보여야 하는 것 |
|---|---|---|
| 1 | 1층에서 몬스터와 싸운다 | 파티 창 이름 옆에 삼각형 세 칸 — 처음엔 모두 비어 있고, 차례가 와도 차지 않는다 |
| 2 | 행동을 정할 때 E를 여러 번, Q를 누른다 | E마다 찬 삼각형이 뼈빛으로 밝아지며 조금 올라간다(가진 만큼까지) · Q로 하나씩 내려간다 |
| 3 | 1개·2개를 얹고 공격한다 | 얹지 않을 때보다 피해 숫자가 크다(약 1.3배·1.6배) · 쓴 만큼 삼각형이 빈다 |
| 4 | 방어를 한 번 하고 다음 차례를 본다 | 방어로 하나 차 있다(최대 셋) |
| 4b | 기세를 얹지 않고 기본 공격(빗나가도) | 공격 뒤 삼각형이 하나 더 찬다 · 기세를 얹은 공격 뒤에는 차지 않는다 |
| 5 | 셋을 모두 얹고 기본 공격 | 두 번 친다(피해 숫자 두 개) |
| 6 | 셋을 얹은 채 정수 스킬(피해 있는 것) | 그 스킬 피해가 약 2배 |
| 7 | 얹은 채 방어·아이템·피해 없는 스킬을 고른다 | 삼각형이 내려가고 기세는 쓰이지 않는다 |
| 8 | (동료 — 디버그 F1 "동료 들이기") 동료 행동을 미리 정할 때 E | 그 동료가 가진 만큼만 얹을 수 있다 · 적 쪽에는 삼각형이 없다 |
| 8b | 같은 몬스터 여럿과 맞닥뜨린다(4일 차 이후 1층 무리, 균열 연전) | 시작 안내가 "고블린 무리와 맞닥뜨렸다."처럼 묶인다 · 무대 이름표에 A·B가 없다 · 소환·분열로 생긴 적도 꼬리표가 없다 |
| 9 | 느낌 | 아껴 모을지·바로 쓸지 고민이 되는지, 배율(`balance combat.rev`)이 너무 세거나 약하지 않은지 |
