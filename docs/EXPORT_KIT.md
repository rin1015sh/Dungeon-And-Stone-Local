# 다른 프로젝트로 넘길 것 (2026-11-21)

모으기: `python3 tools/export_kit.py <출력 폴더> [--only=kit,monsters,…] [--zip]` (`--list` = 크기만).
저장소 안 경로를 그대로 둔 채 복사한다(그림 도구가 서로 찾는 경로가 안 깨지게). `.import` · `__pycache__` · `*_orig` 백업은 뺀다.

## 묶음별로 알아 둘 것

- **그림 형식**: 전부 코드가 그린 WebP(투명 배경). 그림체 = 3D 점토 몸 · 레이캐스트 장면을 찍고 손그림 마감(`docs/ART.md`). 새 그림도 같은 도구로 같은 그림체를 낼 수 있다 — 도구째 넘기는 이유.
- **맵 걷기 시트**(`actors` · `monsters`): 칸 72×108(그림 px, 화면에서는 ×0.5), 줄 = 아래 · 왼쪽 · 오른쪽 · 위, 칸 5 = 걸음 A · 반걸음 A · 섬 · 반걸음 B · 걸음 B, 걷기 순서 `[2,1,0,1,2,3,4,3]`, 원점 = 발(아래 4px). 읽는 코드 `src/explore/view/ActorSheet.gd`. 몬스터는 `_rise`(등장) · `_walk` 시트가 따로 있는 종이 있다.
- **바닥 재질**: 이음매 없이 반복되는 타일 그림. 어느 타일 id가 어느 그림 · 색 · 걷기 가능인지는 `data/tiles.json`. 키트 쪽 목록은 `assets/dungeon_kit/kit.json`(분류 · 칸 · 크기), 설명은 `docs/DUNGEON_KIT.md` · `docs/asset_library/`.
- **벽**: 윗면(`wall_tops`) · 앞면(`wall_faces`) 시트를 3/4 시점으로 쌓는다. 동 · 서 · 남 벽면은 아직 없다(북면만).
- **도시 집**: 집 한 채 = `houses/p<k>.webp` 그림판 + `index.json`(자리 · 크기) · `mask.json`(가림) · `doors.json`(문 자리).
- **코드**: Godot 4.7 GDScript, 정적 타이핑. 오토로드를 거의 안 쓰지만 `ChoiceGrid`가 `AudioBus`를, 대부분이 `JsonUtil` · `data/render.json` 설정 키를 본다 — 옮길 때 그 키(팔레트 · 글꼴 · 창 크기)만 새 `render.json`에 옮기면 된다. `explore_code`는 던전 앤 스톤의 세션 · 지도 클래스에 묶여 있어 그대로는 안 돈다(구조 참고용).
- **소리**: 사용자가 따로 받아 준 음원이다. 새 프로젝트를 공개 · 판매하려면 받은 곳의 라이선스를 다시 확인한다.

## 가져가지 않는 것

전투 규칙(CTB · 큰 몸짓 · 동전 판정) · 정수 · 스킬 · 몬스터 수치 · 아이템 공식 · 도시 규칙 · 층 · 균열 · 지도 데이터 · 원작 설정 문서(CANON · LORE) · 글(서적 · 대사). 원작 소설에서 온 이름 · 설정이라 새 게임(특히 판매할 게임)에 쓰면 안 되고, 규칙은 새 게임에 맞지 않는다.
그림 **파일 이름**에 원작 지명 줄임(`bf` 핏빛성채 등)이나 몬스터 id가 남아 있다 — 그림 자체는 우리가 코드로 그린 것이니, 새 게임에서는 이름만 바꿔 쓰면 된다.

## 새 프로젝트로 옮기는 법

1. 새 저장소(새 세션)에 이 저장소도 같이 붙인다.
2. `python3 tools/export_kit.py ../new_game` (필요한 묶음만 `--only=`).
3. 새 프로젝트에서 `godot --headless --path . --import` → 그림이 들어온다. 도구를 쓰려면 `docs/TOOLS.md`의 그림 명령을 새 경로로 돌린다.
