# 스탯이 바꾸는 것 · 전투 공식 정리 (2026-10-18 기준)

코드(`DamageCalc`·`Combatant`·`BattleRules`·`StatusSet`·`RiftHazards`·`Vision`)와 데이터(`balance.json`·`resources.json`·`statuses.json`)에서 그대로 옮겼다.
수치는 모두 `data/balance.json`에서 바꾼다(괄호 안 = 키). 대부분 임시값이다.

> **회피율 스탯은 따로 없다.** 회피 = 1 − 상대 명중률이고, 지키는 쪽이 회피에 쓰는 것은 **민첩**뿐이다(명중 공식의 민첩 차).

## 1. 주 스탯 5종 — 1점 올리면 무엇이 바뀌나

| 스탯 | 바뀌는 것 | 1점당 |
|---|---|---|
| **근력** `str` | 물리 공격력 | +2 (`combat.phys_atk_per_str`) — 스킬 `str_bonus`가 있으면 +2+k |
| | 탐험 위험: 밧줄 다리(빙하굴, DC 14) | 성공률 +4%p |
| | 녹색 탄광 3챕터 출구 | 40 이상이면 폭약 없이 부숨 |
| **민첩** `agi` | 전투 속도(CTB) | 속도 = 민첩 + 5 → 행동 빈도 비례 |
| | 명중(공격할 때) · 회피(맞을 때) | 민첩 차 1점당 명중 ×(1 ± 0.005) |
| | 치명타율 | +0.3%p (`combat.crit_per_agi`) |
| | 도주 확률 | 아군 평균 − 적 평균 민첩 1점당 +2%p |
| | 함정 피하기·해제, 비탈·빙판 같은 위험 | 성공률 +4%p |
| **물리내성** `p_res` | 물리 방어(받는 물리 피해 감소) | 방어 계수 100/(100+4×값) |
| | 최대 생명력 | +3 (`hp.per_p_res`) |
| | 마비 저항 | +1%p (최대 60%) |
| | 강철의 묘 함정 | 30 이상이면 밟아 부숨(발동 안 함) |
| **항마력** `m_res` | 마법 방어(받는 마법 피해 감소) | 방어 계수 100/(100+4×값) |
| | 상태 저항: 기절·석화·진압·저주의 손길 | +1%p (최대 60%) |
| | 진압 | 25 이상이면 면역 |
| **정신력** `int` | 마법 공격력 | +2 (`combat.mag_atk_per_int`) |
| | 상태 저항: 기절·혼란·봉인·부엉이 울음 | +1%p (최대 60%) |
| | 숨은 함정 탐지(옆 칸에 올 때 한 번) | 성공률 +4%p |
| | 강철빙벽(아이스 오크 주술사 정수) 보호막 | 정신력 × 4 |

- 기절 저항은 정신력 + 항마력을 **합쳐서** 1점당 1%다.
- 레벨이 올라도 주 스탯은 오르지 않는다(생명력·영혼력만 오름).
- 몬스터의 최대 생명력은 공식이 아니라 몬스터 데이터의 고정값이다. 물리내성이 생명력을 늘리는 것은 탐험가에게만 해당한다. **근력은 생명력에 들어가지 않는다**(2026-10-19 — 생명력은 정수 흡수로 오른다).
- 아직 없는 것: 근력의 소지 중량, 항마력 400 제압 면역(`stats.json` 설명에만 있음). 기력·마력 자원은 꺼져 있다(예약 공식: 기력 = 100 + 물리내성×2, 마력 = 20 + 정신력×2).

## 3. 전투 공식

### 피해
```
물리 공격력 = 무기 공격력(맨손 2, 몬스터는 natural_weapon) + 근력 × 2
마법 공격력 = 스킬 base + 정신력 × 2

피해 = 공격력 × 스킬 위력
       × 방어 계수 100 / (100 + 방어 × 4)      ← 물리 = 물리내성, 마법 = 항마력
       × 패시브 배율(power_vs_status 등)
       × 편차 (0.9 ~ 1.1)
       × 약점 배율(약점을 노려 맞히면 ×2)
       × 치명타 ×1.5
       × 상성(약점·면역) × 받는 피해 수정자 × 주는 피해 수정자
       × 속성 (1 − 대상 내성×1%) × (1 + 공격자 감응도×2%)
최소 1 (면역이면 0)
```
- 방어 계수 예: 방어 0 → 100%, 10 → 71%, 25 → 50%, 50 → 33%, 100 → 20%.
- 방어 무시: 스킬 `defense_ignore`(0.2 = 방어의 20% 무시) + 패시브 합(최대 100%), `ignore_defense`면 방어 0.
- 받는/주는 피해 수정자는 **곱한다**: 방어 태세 −50% × 피의 장막 −40% = ×0.3.
- 추가 속성 피해(rider)는 명중·방어 없이 상성·수정자·내성·감응도만 따른다.

### 명중 (= 상대의 회피)
```
명중 = (스킬 명중(기본 95) + 명중률 스탯) / 100 × (1 + (공격자 민첩 − 대상 민첩) × 0.005)
약점 노리기면 × 0.6
30% ~ 100%로 제한
```
- 예: 명중 95, 민첩 차 +10 → 99.75%. 민첩 차 −20 → 85.5%. 실명(−30) + 민첩 차 −20 → 58.5%.
- 대상에 `always_hit`(자석)이 있으면 100%.

### 치명타
```
치명타율 = 5% + 민첩 × 0.3% + 스킬 crit_bonus + 패시브 crit_bonus + 공격자 상태 crit_bonus (최대 60%)
치명타 피해 ×1.5
치명상(즉사): 치명타가 들어가 대상 생명력이 30% 이하로 남으면 10% 확률로 즉사 (양쪽 모두)
```
- 예: 민첩 10 → 8%, 20 → 11%, 50 → 20%.

### 행동 순서 (CTB)
```
속도 = 민첩 + 5 (최소 1)
틱마다 게이지 += 속도, 100이 되면 행동 → 게이지 −= 100 + 스킬 delay_cost
먼저 마주친 쪽(선공)이 시작 게이지 +50
```
- 예: 민첩 10(속도 15) vs 20(속도 25) → 1.67배 자주 행동.

### 도주
```
도주 = 50% + (아군 평균 민첩 − 적 평균 민첩) × 2%p, 10% ~ 90%
수호자·변이 수호자·계층군주가 있으면 불가. 속박(no_flee)도 불가
```

### 상태이상 저항
```
저항 확률 = 상태의 resist 스탯 합 × 1%, 최대 60% (적이 건 것만)
```
| 상태 | 저항 스탯 |
|---|---|
| 중독 | 독 내성 |
| 기절 | 정신력 + 항마력 |
| 마비 | 물리내성 |
| 석화 · 저주의 손길 | 항마력 |
| 진압 | 항마력 (25 이상 면역) |
| 서리 · 빙결 | 냉기 내성 |
| 혼란 · 봉인 · 부엉이 울음 | 정신력 |

나머지 상태(출혈·공포·실명·속박 …)는 저항 스탯이 없다(면역 패시브로만 막음).

### 그 밖의 전투 수치
- 방어 명령: 받는 피해 −50%(1차례).
- 주기 피해: 출혈 3 · 중독 2 · 화상 4 · 부패 2 (차례당, 중독·화상은 속성 내성으로 줄어듦).
- 영혼력 0 → 영혼탈진(정신력·항마력 −20%, 스킬 못 씀, 최대치 10%까지 차면 풀림).

## 4. 탐험 판정

```
위험·함정 성공률 = 50% + (스탯 − DC) × 4%p, 10% ~ 95%
```
| 대상 | 스탯 | DC |
|---|---|---|
| 1층 고블린 덫 — 탐지 / 해제 / 모르고 밟을 때 피하기 | 정신력 / 민첩 / 민첩 | 7 / 4 / 14 |
| 1층 물기 젖은 비탈 | 민첩 | 8 |
| 강철의 묘 함정 — 탐지 / 해제 / 피하기 | 정신력 / 민첩 / 민첩 | 9 / 4 / 18 (물리내성 30 이상이면 밟아 부숨) |
| 빙하굴 빙판 / 비탈 / 밧줄 | 민첩 / 민첩 / 근력 | 12 / 14 / 14 |
| 녹색 탄광 출구 | 근력 40 이상이면 폭약 없이 통과 | |

- 시야 = min(층 상한, max(주변광, 광원, 1m) + 시각 × 0.1m).
- 이동 속도는 스탯과 무관(1칸 = 0.02시간).
- 탐험 은신은 스탯이 아니라 정수 스킬의 `field_stealth`로만.

## 5. 자원 공식

| 자원 | 최대치 | 회복 |
|---|---|---|
| 생명력 | 50 + 레벨×10 + 물리내성×3 + 정수 생명력(9등급 비원딜 8~13 … 5등급 30~50, 원딜은 절반 — `essences.md`) | 자연재생력×0.1/시간, 휴식 중 최대치 5%/시간 |
| 영혼력 | 30 + (Lv5까지 레벨당 +10, 그 뒤 +30) | 차례당 2% · 시간당 5% × (1 + 영혼 재생력×1%), 휴식 중 10%/시간 |
| 허기 | 100 | 시간당 −1 × (1 + 식욕×1%) × max(0.2, 1 − 소화력×1%). 30% 이하 허기, 10% 이하 굶주림, 0 아사(생명력 −2/시간) |

## 6. 스탯을 올리고 내리는 곳

**올리는 것**
- 종족 굴림(캐릭터 생성): 인간 근력·민첩 8~12 · 물리내성 5~8 · 항마력 4~7 · 정신력 6~10 / 바바리안 근력 15~20 · 민첩 7~11 · 물리내성 9~13 · 항마력 2~4 · 정신력 2~6 · 식욕 10~20.
- 정수 흡수: 최대 생명력(`resource_ranges.hp`)과, `stat_ranges` 안에서 정수로 굴린 값이 그대로(flat) 붙음. 수호자 정수(무지갯빛)는 ×1.5 — `docs/balance/essences.md`.
- 정수 패시브의 수정자(예: 칼날늑대 정신력 +2, 아울베어 명중률 +5).
- 도시 훈련(100스톤): 30% 확률로 근력·민첩·물리내성 중 하나 영구 +1. 독서(30스톤): 25% 확률로 정신력 +1.
- 아이템: 장비 수정자, 먹는 아이템의 영구 스탯(고블 쿼츠 독 내성 +3 1회, 마력이 깃든 얼음 조각 냉기 내성 +3 1회, 빙정 냉기 감응도 +3 최대 3회).
- 전투 버프 상태(무리 사냥 근력 +10%, 트롤의 광분 근력·민첩·물리내성 +40% …).

**내리는 것**
- 피로도 50 이상 "지침": 민첩·정신력 −10% / 80 이상 "탈진": 근력·민첩·정신력 −20%.
- 허기 30% 이하: 근력·민첩 −5% / 10% 이하: 근력·민첩 −30%, 생명력 재생 없음.
- 디버프: 공포 민첩 −10% · 속박 민첩 −20% · 서리 민첩 −10% · 둔화 민첩 −8% · 실명 명중률 −30 · 탈진 근력·민첩·물리내성 −30% · 영혼탈진 정신력·항마력 −20% 등.
- 퍼센트 수정자는 `(기본 + flat 합) × (1 + percent 합)`으로 들어간다(같은 스탯의 퍼센트는 더한다).
