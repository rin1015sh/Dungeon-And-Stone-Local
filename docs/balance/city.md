# 도시 규칙 값 (2026-10-15 확정 — 임시값)

사용자 요청 "미정인 값들 알아서 정해서 넣어 줘"로 `data/city.json`·`data/activities/*.json`의 미정(null) 38개를 모두 채웠다.
원문 수치가 없으므로 전부 **임시값**(`"source": "placeholder"`)이다. 바꾸려면 아래 위치의 값을 고치면 바로 적용되고,
실행 중 시험은 디버그 패널(F1) "도시 규칙 값 임시로 바꾸기"(저장 안 됨). 가정 ASSUMPTIONS CT26.

기준: 시작 소지금 500 스톤, 9등급 마석 20 · 8등급 100 · 7등급 300 스톤, 돌빵 20 · 마른 식량 300 · 횃불 10000 · 하급 포션 20000 스톤.
도시 생활비는 마석 몇 개로 감당되게 작게, 미궁 한 번(최대 168시간)으로 피로도가 절반쯤 차게 잡았다.

## 활동 (`data/activities/<id>.json`)

| 활동 | 이용료(스톤) | 효과 |
|---|---|---|
| 여관 · 휴식 `inn_rest` | 50 | 피로도 −40 |
| 여관 · 식사 `inn_meal` | 20 | 소문 얻을 확률 50% |
| 도서관 · 독서 `library_read` | 30 | 정보 얻을 확률 40% · 정신력 +1 확률 25% · 피로도 +10 |
| 신전 · 봉사활동 `temple_service` | 0 | 신전 공적치 +10 |
| 신전 · 정수 제거 `temple_remove_essence` | 0 (제거 비용은 기존 500만 → ×2) | — |
| 훈련장 · 훈련 `training_train` | 100 | 근력·민첩·물리내성 중 무작위 하나 +1 확률 30% · 피로도 +20 |
| 상점 · 구매·판매 `shop_trade` | 0 | 창구(아래 상점) |
| 은행 · 맡기기·찾기 `bank_account` | 0 | 창구(아래 은행) |

행동력: 시설 입장 1(`facility_entry_cost`), 순당 3. 시설 안 활동은 행동력 0(사용자 결정).

## 피로도 (`city.json fatigue`)

| 항목 | 값 |
|---|---|
| 시작 · 최소 · 최대 | 0 · 0 · 100 |
| 미궁 시간 1시간마다 `per_hour` | +0.3 (168시간 ≈ +50) |
| 미궁 휴식 1시간마다 `per_rest_hour` | −2.5 (시간 경과 +0.3과 합쳐 −2.2, 8시간 휴식 ≈ −18) |
| 전투 차례마다 `per_combat_turn` | +0.5 |
| 한 칸 이동마다 `per_step` | 0 (시간으로만 쌓인다) |
| 단계 50 이상 "지침" | 민첩 −10%, 정신력 −10% |
| 단계 80 이상 "탈진" | 근력 −20%, 민첩 −20%, 정신력 −20% (가장 높은 단계 하나만) |
