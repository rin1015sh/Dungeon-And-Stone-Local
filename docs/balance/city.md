# 도시 규칙 값 (2026-10-15 확정 — 임시값)

사용자 요청 "미정인 값들 알아서 정해서 넣어 줘"로 `data/city.json`·`data/activities/*.json`의 미정(null) 38개를 모두 채웠다.
원문 수치가 없으므로 전부 **임시값**(`"source": "placeholder"`)이다. 바꾸려면 아래 위치의 값을 고치면 바로 적용되고,
실행 중 시험은 디버그 패널(F1) "도시 규칙 값 임시로 바꾸기"(저장 안 됨). 가정 ASSUMPTIONS CT26.

기준: 시작 소지금 500 스톤, 9등급 마석 20 · 8등급 100 · 7등급 300 스톤, 돌빵 20 · 마른 식량 300 · 횃불 10000 · 하급 포션 20000 스톤.
도시 생활비는 마석 몇 개로 감당되게 작게, 미궁 한 번(최대 168시간)으로 피로도가 절반쯤 차게 잡았다.
