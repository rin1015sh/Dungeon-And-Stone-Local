# 10층 밸런스 곡선 (기획안 — 게임 데이터에는 아직 적용 안 함)

`python3 tools/balance_curve.py`가 만든다. 가정과 공식은 그 파일 맨 위, 기획 설명은 `docs/plans/balance_10floors.md`.
수치는 '이 층을 도는 기준 탐험가'에 맞춘 **기준값**이다 — 몬스터마다 성격(아래 §5)에 따라 ±30% 흔든다.
