# 몬스터 정수 정리 — 스탯 · 색깔별 스킬 (2026-10-19 기준, 50종)

`data/essences/*.json` + 정수판 스킬 `data/skills/ess_*.json`에서 뽑았다. 데이터를 고치면 이 표는 낡는다(데이터가 정본).

**읽는 법**
- **스탯·생명력**: 정수마다 **고정값**이다(굴림 없음 — 2026-10-19, J13). 흡수하면 그 값이 그대로 붙는다. **수호자 정수는 무지갯빛 — 액티브 전부 + 스탯·생명력 ×1.5.**
- **색**: 일반 정수는 표의 색 중 하나로 떨어지고, 그 색의 스킬 하나만 얻는다.
- **위력**: 공격력(물리 = 무기 + 근력×2, 마법 = 기본값 + 정신력×2)에 곱하는 값. 정수판은 몬스터 원래 스킬보다 위력 ×0.85 · 상태 확률 ×0.75 · 비용 ×1.2로 약하다.
- 상태 괄호 = 그 상태가 바꾸는 스탯. 확률이 없는 상태는 반드시 걸린다(저항은 따로). 공식은 `docs/balance/stats.md`.
