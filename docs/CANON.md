## 1. 정체성과 금지 사항

- 소설 『게임 속 바바리안으로 살아남기』의 작중 게임 「던전 앤 스톤」을 만든다. **비상업 팬 프로젝트**, 웹(itch.io) 공개 예정.
- 장르: 미궁은 3/4 쿼터뷰 실시간 탐험, 전투는 **민첩 기반 CTB 턴제**(피어 앤 헝거식 정면 화면), 하드코어 로그라이크(사망 = 영구 삭제).
- 핵심 재미: 어둡고 불친절하지만 **모든 것은 공략 가능** — 히든 피스·숨은 조건·정보의 가치. 불합리한 즉사 금지.
- 금지: 원작 실명 인물(NPC는 직함만), 현실 쪽 설정(빙의·커뮤니티·GM…), 원작 문장 복사. 설정(규칙·수치·명칭)만 가져오고 문장은 새로. 원문에 없는 수치는 `"source": "placeholder"`.
- 화면 문구 규칙: **부연설명 금지**(무엇인지·어떻게 하는지 설명하는 문장, 조작 안내줄, 소개 `desc_ko` 새로 만들지 않음 — 이름·수치·상태·못 하는 이유만), **결과 문구는 서술형 장면**("고된 훈련으로 근육통만 생겼다").

## 2. 게임 흐름

타이틀(새 탐험가 / 이어하기) → 캐릭터 만들기(이름·종족·템플릿·스탯 굴림) → **도시 라비기온**(순 달력·행동력·시설 6곳) → 하순이 끝나면 저절로 **차원광장**(포탈은 한 달에 한 번, 한 칸 저장은 여기서만) → **미궁 1층** → 층 폐쇄(168h)·포기 → 결과 화면 → **도시 다음 달 상순** → 반복. 사망 → 결과 화면 → 타이틀(저장 삭제). (CT4·CT6·CT31·CT32)

- 원작과 다르게 정한 것: 귀환은 "다음 날 정오"가 아니라 **다음 달 상순**, 자동 저장 대신 **차원광장 한 칸 저장**. 묘비 목록은 아직 없다.

## 3. 캐릭터

- **종족**: 인간·바바리안만 켜져 있다(드워프·요정·수인·용인은 데이터만, `enabled: false`). **템플릿**: 전사·검사·창술사·궁수.
- **스탯**: 주 스탯 5종(근력·민첩·물리내성·항마력·정신력) + 주 스탯으로 대체할 수 없는 세부 스탯 12종(시각·식욕·소화력·자연재생력·영혼 재생력·명중률·감응도 화염/냉기·내성 화염/냉기/독/어둠). 나머지 세부 스탯은 지웠다(ST1~ST5). 새 세부 스탯은 고유 효과가 있을 때만.
- **자원**: 생명력 `50 + 레벨×10 + 물리내성×3 + 근력×1.5`, 영혼력 Lv1 30(5레벨까지 +10, 이후 +30), 허기 100(미궁 안에서만). 기력·마력·신성력·**스트레스는 꺼진 예약 자원 — 쓰지 않는다**. (L2·FE1)
- **피로도**: 자원이 아닌 별도 수치 0~100(도시·미궁 공용). 미궁 시간당 +0.3·전투 차례 +0.5·휴식 시간당 −2.5, 여관 휴식 −40·식사 −15, 맑은 샘 −8. 50 지침(민첩·정신력 −10%)·80 탈진(근력·민첩·정신력 −20%). (CT26·FE1)
- **레벨**: 누적 공적 0/8/50/250/660/1000/1400/2600/3400/4400/18000, **만렙 11**. 공적 = 종별 첫 처치(10 − 등급) · 수호자 +3(반복) · 계층군주 +15 · 포탈 +2. 레벨 = 정수 슬롯 수, 레벨이 내려가면 정수가 무작위로 잠긴다. (L1~L10)
- **정수**: 50종(1층 필드 10 + 핏빛성채 15 + 빙하굴 11 + 녹색 탄광 7 + 강철의 묘 7, 수호자 정수 6 = 무지갯빛). 패시브 1 + 색 → 액티브. **얻는 길은 전투 장면의 드롭 줍기뿐**("획득할까?" → 받을 사람 → 바로 흡수, 두고 가면 사라짐 — 흡수 대기·만료 없음). 패시브·이능이 겹치면 못 받는다. 제거 = 신전(유료). (J1~J10·UI13)
- **소지품**: 격자 가방 10×6, 장비 11칸(양손·반지 2).

## 4. 미궁

- **시간은 실시간**: 실제 1초 = 게임 0.1시간. 이동(8방향 연속)은 시간을 쓰지 않고 민첩에 따른 이동 간격만. 전투·일시정지·창·선택 창·디버그·포커스 잃음이면 멈춘다. 대기(Space 1h)·휴식(Z 8h)은 즉시. 폐쇄 24/6/1시간 전 경고. (X17~X21)
- **시야**: min(층 상한, max(주변광, 광원, 최소 1m) + 시각 보정). 1층은 수정 빛 6m(상한 9m), 팔 끝 암흑지대는 맨몸 1m·횃불 7m. 휴식 회복은 안전지대(기념비 둘레)만.
- **1층 수정동굴 = 733×733 고정 지도**(모든 게임에서 같은 지형 — `data/maps/f1_crystal_cave.json`): 거대한 십자가(중심부 153² + 팔 288×135) 안의 **미로 동굴** — 꼬인 굴 + 중간 크기 공동·방(거대 공동 없음), 지하 호수·석순 기둥·수정 무리, 막다른 길 없음, 통로 폭 ≥ 2. 중심 대현자 기념비, 팔 끝 암흑지대 안 2층 포탈 4개. 기념비에서 한 방향으로만 가도 포탈에 닿는다(약 450~470걸음 ≈ 10시간). **시작 위치·몬스터·동굴 요소 상태만 입장마다 새로.** (CR1~CR24)

- **동굴 요소** 25종 203곳(`data/events`, 자리 = 고정 지도 `features`): 탐험가 시체(구역별 상처·전리품·신원패)·버려진 마석·꺼진 모닥불(휴식 보너스)·부서진 장비·숨은 보급품(정신력 탐지)·공물 더미·맑은 샘(마시기 피로 −8·씻기 출혈 해제·물 담기)·수정 물방울 종유석(영혼력)·석순 숲·수정 버섯·늑대 잠자리(지키는 무리·도감)·노움 잡동사니·노움 은닉처(노움이 쫓아옴)·갉아먹힌 시체 더미(부패)·고블린 모닥불(지키는 무리)·고블린 덫(숨음)·젖은 비탈·글만 나오는 분위기 요소. 살피기 = **F**. **하지 않기로 한 것**: 지도를 바꾸는 요소(벽 깨기·지름길), 수정 맥, 메아리 공동, 쪽지 지도, 찬 바람 굴, 벽 표식·화살표·낙서, 호수 마시기 판정. (FE1~FE12)

## 5. 전투

- CTB: 속도 = 민첩 + 5. 순서 목록은 화면에 없다. 명세 V2의 "라운드제"는 쓰지 않는다(사용자 결정 2026-10-12).
- **화면 = 피어 앤 헝거식 정면 구도**: 어둠 속 빛 웅덩이 위에 적 정면(손그림 52종), 아래 앞줄에 아군 뒷모습·옆모습, 아래 창 = 명령 4칸(공격·스킬·방어·아이템, **도주는 스킬 목록 맨 끝**) + 파티 창. 아군 전원의 행동을 먼저 정하고 실행. 적 생명력은 숨김(조사로만), 피해 숫자는 몸 위, 빗나가면 "회피". 끝나면 드롭을 하나씩 줍는다. (UI7~UI14)
- 공식(명세 V2 §1): 물리 = 무기 + 근력×2, 마법 = 기본 + 정신력×2, 방어 100/(100+방어×4), 명중 = (95 + 명중률) × (1 + 민첩 차×0.005), 치명 5% + 민첩×0.3%(×1.5), 도주 50% + (아군 − 적 평균 민첩)×2%p(10~90%, 수호자·군주전 불가).
- 모든 아군의 기본 스킬: 대화·조사. 상성(약점·면역)이 핵심 — 늘 공략법이 있어야 한다.

## 6. 도시 — 라프도니아 라비기온 구역

- 횡스크롤 거리 그림(피어 앤 헝거 2풍)에서 시설을 고른다. 시설 6곳: 여관(휴식 = 피로 −40·생명력/영혼력 전부, 식사 = 피로 −15·남은 음식), 도서관(독서 — 정보·정신력 확률·피로 +10), 신전(정수 제거·봉사 공적치), 상점(사고팔기, 마석도), 은행(맡기기·찾기·이자), 훈련장(능력치 확률·피로 +20).
- 한 달 = 상순·중순·하순, 순마다 행동력 3. **행동력은 시설에 들어갈 때만 1**, 시설 안 활동 한 번 → 저절로 거리로(나가기 버튼 없음). 하순이 끝나면 차원광장. 날씨는 순마다 무작위. 값은 모두 임시값(`docs/balance/city.md`, CT26). (CT1~CT33)
- 없는 것(명세가 오면): 길드(정보 구매·동료), 환전소, 대장간, 잡화점, 대신전 치료·특식, 신관 영입, 소문·정보를 다시 보는 창.
