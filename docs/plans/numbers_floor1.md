# 1층 넘버스 후보 (제안 — 2026-10-29)

> 사용자 2026-10-29: "넘버스 9999개는 현실성이 떨어지나?" → 번호는 세계의 이름표, 게임엔 수호자마다 손으로 만든 후보만.
> "여러 개 떨어질 수 있고 일단 제안해봐. 근데 넘버스 아이템 개수는 좀 늘리고 싶음" → 같은 번호가 여러 번 나올 수 있다(IT12), 수호자마다 12개.
> **이 문서는 제안이다** — 이름·종류·고유 효과의 개념만. **수치(공격력·스탯·확률)는 사용자가 정한다**(C18). 아직 데이터·그림 없음.

## 1. 틀

- **번호대**: 1층 = No.9999~7000(`docs/balance/curve.md` §8-2). 번호가 작을수록 귀하고 강하다.
- **양**: 균열 수호자 4마리 × 12개 + 변이 수호자 2마리 × 5개 + 1층 공용 6개 = **64개**. 10층까지 같은 비율이면 약 500~600개.
- **드롭**: 지금처럼 수호자 처치 때 33%(`numbers_chance`). 걸리면 그 수호자 목록(+ 1층 공용)에서 무게대로 하나.
  - 무게(제안): 9xxx = 6 · 8xxx = 3 · 7xxx = 1. 공용 6개는 무게 ×0.5.
  - 변이 수호자(캠보르미어·키르뒤)는 자기 5개(무게 ×2) + 원래 수호자 목록.
  - 같은 번호가 또 나와도 된다(IT12) — 이미 가진 번호라도 거르지 않는다.
- **데이터 모양(제안)**: 균열 `numbers` = `[{"item": id, "weight": n}]`(지금은 id 배열), 아이템 `rarity: "numbers"`·`number: 9712`, 고유 효과는 장비의 `equip.passive`(= 몬스터·정수 패시브와 같은 키, `src/combat/Passives.gd`). 장착하면 `Actor.add_passive`, 벗으면 `remove_passive` — **이 연결은 새 코드**.
- 아래 "키" 열 = 이미 있는 패시브 키로 되는 것. **새** = 키를 새로 만들어야 하는 것.
- 이름은 새로 지었다. [원] = 명세(`docs/PROMPT.md`·`PROMPT_FLOOR1_V2.md`)에 있던 것.
