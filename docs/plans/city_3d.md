## 0. 한 줄 요약

**옆으로 긴 거리 그림(CityStreet)을, 위에서 비스듬히 내려다보는 실제 3D 구역 하나(라비기온 7구역 — 동서 160m × 남북 220m)로 바꾼다.**
차원광장은 따로 떨어진 화면이 아니라 **구역 한가운데 광장**이 된다. 플레이어는 W/A/S/D로 골목을 걸어 시설 문 앞에서 Enter로 들어간다.
건물은 손으로 모델링하지 않고 **필지 데이터 → 코드가 짓는 조립식 건물**(지금 그림을 코드가 그리는 것과 같은 길)로 만든다.

## 2. 참고 그림에서 가져올 것 (첨부 그림 읽기)

`reference.webp`는 **위에서 비스듬히(약 55°) 내려다본, 원근이 거의 없는 쿼터뷰**다. 이 느낌을 그대로 목표로 잡는다.

1. **빈틈이 없다** — 건물이 벽을 맞대고 붙어 있고, 길은 건물 사이에 남은 틈이다. 공터는 광장·계단참뿐.
2. **높낮이** — 테라스 사이를 계단(넓은 대계단·좁은 골목 계단)과 옹벽이 잇는다. 같은 동네가 위·아래로 나뉜다.
3. **건물 말투가 몇 가지로 반복된다** — 박공·모임지붕의 3~4층 연립(회청·크림·갈색 회벽, 갈색 기와, 지붕창, 굴뚝), 뾰족 아치·첨탑의 고딕 석조, 원통 + 돔 지붕 건물.
4. **바닥이 이야기한다** — 자갈 포석, 흩어진 종이·쓰레기, 통·자루·상자 더미, 무너진 돌, 핏자국 하나.
5. **가로 소품** — 쇠 가로등(대로·광장 쪽에만), 이정표, 기둥 말뚝, 난간, 하수구 덮개.
6. **색** — 채도가 낮은 갈색·회색·흐린 청회색. 밝은 색은 없다(UI45 팔레트와 같은 결).
7. **지도 가장자리는 검은 칸** — 갈 수 없는 곳은 그리지 않는다(구역 밖 = 어둠). → 3D에서는 구역 둘레를 성벽·높은 건물로 막고 그 너머는 안개 속 실루엣.

## 3. 실제 도시처럼 — 라비기온 7구역 짜기

배치도: `docs/plans/city3d/district7.png`.

### 3-1. 이 동네는 어떤 곳인가 (CANON §7에서)
- 라프도니아 = 세상에 남은 **유일한 성채 도시**. 성벽 안에 14구역이 빽빽이 들어찼다 → 땅이 귀하다 → **좁은 필지·높은 건물·좁은 길**(중세 성곽 도시가 실제로 그랬다).
- 7~13구역 라비기온 = 인구 70%, **구역마다 차원광장**. 탐험가가 사는 동네라 광장이 동네의 심장이다 — 모든 길이 광장으로 모인다.
- 7구역은 6구역(노움트리)·컴멜비 쪽 끝 → 라비기온 중에서는 나은 편(꽃상자 그림 등급 2). 그래도 **대로변과 뒷골목의 격차**가 있다.
- 늘 흐리고 마석으로 식량을 만든다 → 그림자가 진하지 않은 흐린 빛, 굴뚝 연기, 가로등은 마석 등(차가운 빛 — 가정, §9).

### 3-2. 땅 — 테라스 셋
| 단 | 높이 | 성격 | 들어선 것 |
|---|---|---|---|
| 상단(북) | +6m | 조용한 석조, 성 안쪽(구역문)에 가깝다 | 신전(첨탑 둘 — 어디서나 보이는 랜드마크) · 신전 앞뜰 · 도서관(원형 열람당·유리 돔) |
| 중단 | 0m | 넓고 밝다, 사람 가장 많음 | 대로 · **차원광장** · 탐험가 길드 · 은행 · 여관 · 공시판 · 정산 천막 |
| 하단(남) | −4m | 좁고 어둡다, 연기·물 냄새 | 시장골목 · 잡화점 · 대장간(수로 옆, 뒷마당) · 바깥 성벽 |

단 사이 = 옹벽 + 계단 넷(대계단 16m 폭 · 골목 계단 · 시장 계단 · 수레용 경사로). 높낮이는 3D로 만드는 가장 큰 이유다 — 2D 옆 그림에서는 못 보이던 "위로 올라가는 동네"가 생긴다.

### 3-3. 길의 위계
- **대로**(폭 16m): 구역문 → 대계단 → 광장. 가로등·포석이 고르다.
- **거리**(5~6m): 시장골목, 테라스마다 동서로 한 줄.
- **골목**(2~4m): 덩어리 사이, 꺾이고 막다른 곳이 있다. 가로등 없음, 빨랫줄·쓰레기.
- **안마당**: 큰 덩어리 가운데(우물·빨래) — 들어가는 통로가 있는 곳만 걸을 수 있다.

### 3-4. 필지와 건물
- 덩어리(블록) 둘레를 **폭 5~9m · 깊이 10m 필지**로 나누고 집마다 한 채(배치도의 갈색 칸 하나 = 집 하나).
- 3~5층, 1층은 가게·작업장·문, 위층은 살림집. 대로변은 높고 반듯하게, 뒷골목은 낮고 기울어지게(위층이 길 쪽으로 튀어나온 집 — 돌출층).
- 집집이 높이·지붕·벽색·창 간격이 달라 같은 줄에서도 지붕선이 들쭉날쭉하다(참고 그림의 핵심).

### 3-5. 시설을 왜 거기에 두나
| 시설 | 자리 | 이유(실제 도시라면) |
|---|---|---|
| 탐험가 길드 | 광장 북서 면 | 포탈·정산을 관리하는 곳이니 광장에 붙는다 |
| 여관 | 광장 동쪽 면 | 원정 전날 묵고 돌아와 마시는 곳 — 광장·성문 옆이 여관 자리 |
| 은행 | 대로변, 계단 아래 | 사람이 가장 많이 지나는 대로에 돌로 지은 단단한 건물 |
| 신전 | 상단, 대계단 위 | 높은 곳에 세워 동네 어디서나 첨탑이 보인다 |
| 도서관 | 상단, 신전 옆 | 조용한 곳. 원형 열람당(참고 그림의 돔 건물) |
| 잡화점 | 하단 시장골목 | 노점·아케이드가 늘어선 장터 거리 |
| 대장간 | 하단 수로 옆 | 불·소음·물이 필요해 실제 도시에서도 변두리 물가에 둔다 |

걸음: 광장 고리에서 여관 20m · 은행 30m · 길드 40m · 잡화점 60m · 신전 80m · 대장간·도서관 약 100m.
지금 실내 걷기 빠르기(`room.walk_tiles_per_sec` 3.15)면 가장 먼 곳이 약 32초 — **거리에서는 초속 4~5m**로 올려 25초 안쪽(가정, §9).

### 3-6. 차원광장
- 지름 36m 원형 광장, 가운데 **세 단 돌 단 위의 돌 고리**(포탈 — 지금 포탈 셰이더를 3D 판에 입힌다).
- 둘레: 길드 정산 천막(저울·직원) · 공시판(조사 의뢰) · 출정을 기다리는 탐험가 무리(순마다 달라짐) · 경비 초소 · 행상 수레(거리 사건 '행상'일 때).
- **평소**: 돌 고리는 꺼져 있고, 다가가 Enter → "아직 열리지 않았다"(못 하는 이유 짧게).
- **하순이 끝나면**: 화면이 광장으로 옮겨 가고(카메라 이동) 포탈이 열린다 → 지금처럼 선택판 "기록을 남긴다 / 포탈로 들어간다".
- **귀환**: 포탈에서 걸어 나오면 바로 정산 천막 앞 — 직원이 신원패를 확인하고 마석을 읊는다(GuildSettle 그대로).
- 다른 구역(8~13구역)의 광장도 같은 꼴이라, 나중에 구역을 늘리면 광장 부품을 그대로 쓴다.

## 4. 화면 — 카메라와 가림

- **카메라 고정**: 남쪽에서 북쪽을 보며 아래로 약 55°, 정사영(원근 없음 — 참고 그림처럼 반듯한 쿼터뷰, 미궁 3/4 시점과 같은 방향감). 회전 없음(키보드 조작이 단순해야 한다 — UI14).
  - 시야: 화면 세로 약 28m(건물 3~4채 깊이). 플레이어를 부드럽게 따라가고 구역 가장자리에서 멈춘다.
- **가림**: 남쪽 건물이 플레이어를 가린다(3~5층이면 골목 하나가 통째로 숨는다). 플레이어 둘레 원 안에서 **카메라 쪽 건물의 지붕·위층을 점무늬로 비운다**(셰이더 discard 디더 — GL Compatibility에서 된다). 실내로 들어가는 문 앞에서도 같은 방법.
- **사람 그림은 2D 그대로**: 플레이어·직원·행인은 지금 탐험 몸 그림(`assets/actors/*.webp` 4방향 걷기 시트)을 3D 안에 세운 판(Sprite3D, 카메라를 향함)으로 쓴다. 새로 3D 사람을 만들 필요가 없고 미궁과 같은 사람이 걷는다.
- **빛**: 늘 흐림 → 강한 해 그림자 대신 부드러운 하늘빛 + 짓기 단계에서 구운 구석 그늘(꼭짓점 AO). 그림자는 흐림에서 끄고 맑은 순에만 약하게(성능 여유를 보고). 가로등·창은 스스로 빛나는 재질 + 바닥 빛 웅덩이(그림 한 장)로 흉내 — 진짜 점광원은 광장 포탈 하나만.
- **날씨**: 흐림(기본) · 비(입자 + 젖은 바닥 번들거림 + 짙은 안개) · 안개(먼 건물이 실루엣으로) · 맑음(드묾, 그림자 조금). `city.json weather`에 3D 항목을 더한다.
- **그림 말투**: 잉크 윤곽(뒤집은 껍질 — 싸다) + 손으로 칠한 듯한 재질 그림(지금 `tools/city_art/Mat.gd` 재질을 3D 재질 아틀라스로) + 피어 앤 헝거식 어두운 색 보정(지금 후처리 셰이더 `post_grade`).

## 5. 만드는 방법 — "코드가 짓는 도시"

이 게임 그림은 전부 코드가 그린다(ART.md). 3D도 같은 길로 간다 — **사람이 모델링 프로그램을 쓰지 않는다**.

```
data/town/district7.json      땅(테라스 높이) · 길 · 계단 · 덩어리 · 필지(집 하나하나) · 시설 문 · 소품 · 사람 자리 · 광장
data/town/styles.json         건물 말투(연립·반목조·고딕 석조·원형 돔·아케이드·작업장) — 층 높이·지붕·창 리듬·벽 재질 후보
        │
        ▼  tools/bake_town.gd(굽기 — bake_floor처럼)
assets/town/district7_*.res    덩어리마다 합친 메시(재질별 한 덩어리) · 걷기 칸 지도 · 가림 정보
assets/town/atlas_*.webp       재질 아틀라스(지붕·회벽·돌·나무·창·문·포석·계단) ← tools/paint_town.gd(+ city_art/Mat 재사용)
        │
        ▼  실행 중
src/city/town/   TownMap(걷기 칸·높이·문·살필 것 — 오토로드 비의존, 헤드리스 시험 가능) · TownWalk(이동·충돌)
src/ui/city/town/ TownView(SubViewport + Camera3D) · TownOcclusion(가림 디더) · TownActors(Sprite3D 사람) · TownWeather · TownPlaza(포탈·천막)
```

- **필지 → 건물**: 필지 하나 = {폭·깊이·층수·지붕(박공·모임·망사드·평)·말투·벽색·1층 꼴(문·가게·아치)·지붕창·굴뚝·돌출층·시드}. 짓는 코드가 벽 상자 → 창·문 칸 → 처마 → 지붕 → 굴뚝을 쌓는다. 같은 시드면 같은 집(그림 도구와 같은 규칙).
- **시설 건물**: 말투 대신 손으로 정한 설계 하나씩(신전 첨탑·도서관 돔·대장간 굴뚝과 뒷마당 …) — `data/town/landmarks`.
- **걷기는 1m 칸 논리 + 부드러운 이동**: 지금 실내(`RoomWorld`)처럼 칸으로 막힘·문·살필 것을 판정하고, 화면에서는 미끄러지게 움직인다. 헤드리스 시험(광장에서 모든 시설 문까지 걸어 닿는가)이 쉽다.
- **소품은 묶어서**: 통·자루·가로등·꽃상자·빨랫줄은 MultiMesh(같은 소품은 그리기 한 번).
- **글은 늘지 않는다**: 시설 이름판은 지금처럼 없다. 문은 검은 테두리(CT77)로 알아본다.

### 5-1. 웹(itch.io)에서 돌아가야 한다 — 예산
GL Compatibility · 스레드 없음 · 외부 플러그인 없음(CLAUDE.md) 안에서:

## 6. 시스템 쪽 바꿀 것

- **CityScreen**: 거리 자리에 `CityStreet` 대신 `TownView`. 전환 중에는 `render.json city.mode`("street" | "town")로 둘 다 살려 둔다.
- **시설 들어가기**: 문 칸을 바라보고 Enter → 행동력 1(CT72 그대로) → 화면 어두워짐 → 지금 실내. 나오면 그 문 앞에 선다.
- **순 넘김**: 행동력을 다 쓰고 나오면 다음 순 — 하늘·날씨·행인이 바뀌는 것으로 보인다(글 없음, UI19).
- **하순 끝 → 광장**: 지금 `PlazaScreen`이 하던 일(포탈 열림·저장·들어가기·귀환 정산)을 `TownPlaza`가 3D 광장에서 한다. 선택판·대화창은 그대로 쓴다.
- **거리 사건**: `CityHappenings`가 사건마다 거리에 놓을 것(행상 수레·깃발·줄 선 사람)을 `data/street_events`에 `town` 항목으로.
- **살필 것**: 거리의 통·상자 일부를 실내처럼 뒤질 수 있게(CT74와 같은 규칙, 한 자리 한 순에 한 번) — 할지 말지는 §9.
- **특별 시설**(CT63 — 거리 끝 D): 구역문으로 걸어가 Enter → "어디로 갈까"(지금 틀 그대로, 갈 곳은 아직 없음).

## 7. 다른 길 — 고르는 데 쓰라고

| 안 | 내용 | 좋은 점 | 나쁜 점 |
|---|---|---|---|
| **A. 실시간 3D**(추천) | 위 §4~§6 그대로 | 걸어 다니는 높낮이 동네, 날씨·시간이 살아 움직임, 구역을 늘리기 쉬움 | 일이 가장 많음, 웹 성능 위험, 코드가 짓는 집이 참고 그림만큼 섬세할지 미지수 |
| B. 3D로 짓고 2D로 굽기 | 같은 데이터로 3D 구역을 지어 **큰 그림 한 장 + 깊이 그림**으로 구워, 실행은 2D(참고 그림이 바로 이런 꼴) | 웹 성능 걱정 없음, 굽는 단계에서 비싼 빛·그늘을 마음껏 | 날씨·시간 변화가 색 곱하기 정도, 가림 처리를 깊이 그림으로 따로, 구역 바꾸면 다시 굽기 |
| C. 2D 타일 쿼터뷰 | 실내처럼 2D 칸 지도로 거리를 그림 | 지금 실내 코드를 그대로 씀, 가장 빠름 | "3D화"가 아님, 높낮이·지붕 겹침 표현이 약함 |

추천: **A안으로 시제품(M0)을 먼저 만들어 웹에서 재 보고**, 성능이나 그림 질이 모자라면 같은 데이터·같은 짓는 코드로 B안으로 물러난다(데이터와 짓는 코드는 두 안이 같다 — 버리는 일이 적다).

## 9. 사용자가 정할 것

1. **A안(실시간 3D) / B안(3D로 짓고 2D로 굽기)** — 추천 A, M0 뒤에 다시 확인.
2. **카메라 회전**: 고정(추천 — 키보드 단순) / Q·E로 90°씩 돌리기(E·Q는 지금 전투 기세에만 쓴다 — 도시에서는 비어 있다).
3. **시설 안**: 1차는 지금 2D 실내 유지(추천) / 처음부터 3D 실내.
4. **동네 크기**: 7구역 하나 160×220m(추천) / 더 작게(광장 둘레만 — 일이 절반) / 더 크게.
5. **거리 걷기 빠르기**: 초속 4~5m(추천 — 가장 먼 시설 25초 안).
6. **거리에서 뒤지기**: 통·상자를 뒤질 수 있게(실내 CT74처럼) / 거리는 구경만.
7. **가로등 빛**: 마석 등(차가운 청백 — 마석으로 사는 도시라는 설정에서 나온 가정) / 기름 등(따뜻한 주황). 원작 원문이 있으면 그쪽.
8. **차원광장 꼴**: 원작 원문(광장 모양·포탈 생김새)이 있으면 받기 — 없으면 §3-6대로.
