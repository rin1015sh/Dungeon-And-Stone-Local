# 정수 패시브·액티브 재기획 (2026-10-19 — 적용함, 아래 7절)

> 사용자 요청: "정수 패시브/액티브가 몇 개 빼면 범용성이 없거나 복붙 — 피해 감소·증가 아니면 물리·마법 피해뿐. 몬스터 컨셉에 맞고 특성을 살리게 재조정."
> 참고 문서(나무위키 「게임 속 바바리안으로 살아남기/설정/정수」 8.1절~)는 이 환경에서 접속이 막혀 **읽지 못했다**. 아래는 우리 명세(`PROMPT_FLOOR1_V2.md`)의 몬스터 컨셉만으로 짠 [창] 초안이다. 원문을 받으면 원작 정수와 대조해 고친다(맨 아래 "원작 대조" 표).
> **스탯·생명력(J11~J13)은 그대로** 두고 패시브·액티브만 다시 짠다. 2026-10-19 데이터에 적용했다(J17 — 7절).

## 1. 지금 문제

정수 50종 패시브 50개·액티브 134개(색 하나 = 한 개, 공유 포함)를 갈래로 나눴다.

| 갈래 | 패시브 | 액티브 |
|---|---|---|
| 수정자(받는/주는 피해 %·스탯 %)만 | 15 | — |
| 피해 + 상태 하나 확률 | — | 72 |
| 자기·아군 버프만 | — | 24 |
| 그 밖(적 상태만·소환·예고·보호막·흡수·조건부 등) | 35 | 38 |

- 같은 계열(늑대 4·고블린 3·데드맨 3·노움 2·구울 2·슬라임 2·스켈레톤 2·아이스 오크 2)이 "위력만 다른 같은 스킬"이다.
- 상태이상이 따로 논다 — 출혈·중독·서리를 쌓아도 그걸 **쓰는** 스킬이 거의 없다.
- 5인 파티(J16)인데 **역할**(앞에서 받기·보호·지원·방해)을 주는 정수가 거의 없다. 대부분 "때리기"다.

## 2. 원칙

1. **정수 하나 = 그 몬스터의 특징 하나.** 패시브는 "늘 붙는 %"보다 **조건 → 반응**(맞으면·때리면·쓰러뜨리면·상태 걸린 적에게·생명력이 낮으면·전투 시작에).
2. **색 = 쓰임새가 다른 스킬.** 한 정수의 색끼리 "공격 / 방해 / 지원(또는 몸 쓰기)"처럼 갈래를 나눈다. 같은 갈래 두 개는 피한다.
3. **키워드로 서로 엮인다.** 아래 6개 키워드는 "쌓는 정수"와 "터뜨리는 정수"가 따로 있어 조합을 만든다.
4. **5인 파티 역할**: 앞줄(받기·끌기) · 뒷줄(쏘기·걸기) · 지원(보호·회복·정화) · 소환. 정수 몇 개로 역할이 정해지게.
5. 새 기능은 꼭 필요한 것만, 가능하면 **이미 있는 키**(아래 표)로.

### 키워드 (쌓기 → 터뜨리기)

| 키워드 | 쌓는 쪽 | 쓰는 쪽(새로) |
|---|---|---|
| **출혈** | 칼날늑대 계열·고블린 검사·데스핀드·블라터 | 핏빛 칼날늑대 "피 핥기"(출혈 중첩만큼 회복·위력), 키메라 울프(출혈 대상 추가 물기) |
| **중독** | 고블린·타락한 노움·시체골렘·홉고블린 광부·아이언 리자드맨·슬라임 | 고블린 궁수(중독 대상 치명), 시체골렘 "살점폭발"(중독 중첩 터뜨리기) |
| **서리 → 빙결** | 서리 늑대·아이스 골렘·아이스 오크·예티·카툼바 | 서리(민첩↓) 3중첩이면 빙결(못 움직임, `on_max_stacks`), 타룬바스(빙결 대상 위력 ×2 + 깨뜨리기) — 이름은 사용자 결정대로 서리 = 민첩 감소, 빙결 = 못 움직임 |
| **속박·넘어짐** | 덫·웜스톤·머미·킹 슬라임·구울 붙잡기 | 비열한 찌르기(속박 대상 치명), 엘더 구울 "짓누르기"(속박 대상 위력↑) |
| **표식** | 수호자의 눈·스켈레톤 아처·캠보르미어 | 표식 대상에게 아군 전원 명중·피해↑ |
| **공포·저주** | 벤시·가고일·머미·데드맨 지휘관 | 공포 대상 행동 건너뛰기↑, 본 나이트 "영혼 베기"(저주 대상 영혼력 더 깎기) |

### 이미 있는 장치 (새로 안 만들어도 되는 것)

패시브: `on_hit`·`on_crit`·`on_hit_filter`·`crit_bonus`·`power_vs_status`·`reflect_melee`·`status_immune`·`start_gauge`·`see_hidden`·`ally_aura`(계열·전원)·`start_summons`·`foe_statuses_on_start`·`self_statuses_on_start`·`turn_end_foe_status`·`regen_per_round`·`status_duration_cap`·`dot_mult`·`mark_first_attacker`·`basic_attack_effects`·`hit_rider`·`defense_ignore`·`on_damaged_by`·`death_effects`·`low_hp_summons`·`revive_once`·`meter_on_damaged`.
효과: `damage`(`power_if_status`·`crit_bonus`·`defense_ignore`·`str_bonus`·`rider`)·`apply_status`·`remove_status`·`restore_resource`·`barrier`·`summon`(`pick`·`rounds`)·`delayed`(예고)·`push_back`·`seal_skill`·`soul_slash`·`split`·`absorb_ally`·`smite`·`shuffle_rows`·`meter`.
상태: `stackable`·`max_stacks`·`on_max_stacks`·`counter`(반격)·`lifesteal`·`on_hit`·`draws_attacks`(끌어들이기)·`break_on_damage`·`grants_immunity`·`heal_mult`·`misdirect`·`consume_on_attack`.

### 새로 필요한 장치 (제안 — 작은 것만)

| 이름 | 하는 일 | 쓰는 정수 |
|---|---|---|
| `consume_status` (효과) | 대상의 상태 중첩을 없애고 중첩 수만큼 위력·회복 | 피 핥기·살점폭발·빙결 깨뜨리기 |
| `power_if_hp_below` (효과) | 대상 생명력이 n% 이하면 위력 ↑(처형) | 샤벨 타이거·고블린 검사 |
| `on_kill` (패시브) | 적을 쓰러뜨리면 효과(회복·게이지·버프) | 구울·데스핀드·블라터 |
| `cover` (상태) | 지정한 아군 대신 맞는다 | 철기병·일디움·데드맨 병사 |
| `gauge` (효과) | 대상 행동 게이지 ± (차례 당기기·밀기) | 스컬 랫·샤벨 타이거·카툼바 |
| 전원 대상 `ally_all` 확장 | 이미 있음 — 동료가 생기면 바로 의미가 생긴다 | 지원 정수 |

## 3. 정수별 재기획 (50종)

표기: **역할** · 패시브 → 새 / 액티브 = 색: 새 스킬(효과 요약). [기존] = 지금 것 유지, [수정] = 손봄, [새] = 바꿈.

### 1층 필드 — 고블린 계열 (덫·독·비열함)

- **고블린** · 방해 — 패시브 [수정] *마비독 칼날*: 근접 적중 20% 마비독 + **속박·마비 대상에게 치명 +15%p**(`power_vs_status` 대신 `crit_bonus` 조건).
  초록 [수정] 덫 생성: 다음 차례 피해 + **속박 1차례**(명세 F7 원래 의도) · 빨강 [기존] 비열한 찌르기(속박·마비 대상 위력↑) · 노랑 [기존] 모래 뿌리기(실명).
- **고블린 검사** · 근딜 — 패시브 [수정] *어설픈 검술*: 베기 치명 시 출혈 → **출혈 대상에게 치명 +10%p**.
  빨강 [수정] 내려베기: **생명력 30% 이하 대상 위력 ×1.6**(`power_if_hp_below`) · 파랑 [기존] 막고 찌르기(반격 자세 — `counter`로 바꿔 맞으면 되찌름) · 초록 [기존] 조잡한 연격.
- **고블린 궁수** · 원딜 — 패시브 [수정] *독화살*: 활 적중 시 중독 → **중독 대상에게 치명 +15%p**.
  보라 [기존] 독화살 사격 · 빨강 [수정] 조준 사격: **한 차례 늦게(delay_cost) 쏘고 방어 50% 무시** · 초록 [기존] 도둑걸음(은신 + 탐험 은신).

### 1층 필드 — 칼날늑대 계열 (무리·출혈)

- **칼날늑대** · 근딜/지원 — 패시브 [수정] *추적 후각*: 숨은 적 노림 + **출혈 대상에게 명중 +15**.
  빨강 [기존] 물어뜯기(출혈) · 노랑 [기존] 칼날 스치기 · 파랑 [수정] 무리 사냥: **아군 전원 근력 +10% + 출혈 대상 피해 +15%** 3차례.
- **거대 칼날늑대** · 앞줄 — 패시브 [기존] *두꺼운 칼날털*(근접 반사) → **반사에 출혈 25%**.
  빨강 물어뜯기(공유) · 노랑 [기존] 몸통 박치기(기절) · 파랑 [수정] 위협 포효: **적 전원 근력 −15% + 자신에게 끌어들이기(draws_attacks) 2차례**.
- **핏빛 칼날늑대** · 근딜(흡혈) — 패시브 [기존] *피 냄새*(출혈 대상 피해↑).
  빨강 [기존] 찢는 이빨(출혈 강) · 보라 [새] **피 핥기: 대상 출혈 중첩을 없애고 중첩×생명력 회복 + 위력↑**(`consume_status`) · 노랑 칼날 스치기(공유).

### 1층 필드 — 구울 계열 (포식·부패)

- **구울** · 근딜 — 패시브 [수정] *네 발 짐승*: 첫 차례 선공 + **적을 쓰러뜨리면 생명력 8% 회복**(`on_kill`).
  빨강 [기존] 할퀴기(출혈) · 파랑 [수정] 달려들기: **뒷줄도 노림 + 명중 80**(원거리 막힘 무시).
- **엘더 구울** · 앞줄 — 패시브 [기존] *썩은 거구*(물리 −5%, 출혈 면역).
  잿빛 할퀴기(공유) · 빨강 [수정] 짓누르기: **속박 대상에게 위력 ×1.5** · 초록 [기존] 썩은 손톱(부패 — 회복 막기).

### 1층 필드 — 노움 계열 (진흙·몸 바꾸기)

- **노움** · 앞줄 — 패시브 [기존] *진흙 몸*(베기·찌르기↓ 둔기↑).
  초록 [기존] 일체화(은신·다음 공격↑) · 노랑 [기존] 진흙 던지기(실명) · 파랑 [수정] 굳히기: **물리내성 +50% + 끌어들이기**(앞줄 탱커).
- **타락한 노움** · 방해 — 패시브 [수정] *오염된 진흙*: 적중 시 가끔 중독 + **중독 대상 받는 피해 +10%**.
  초록 일체화(공유) · 보라 [기존] 저주 진흙(항마력↓) · 갈색 [기존] 썩은 진흙 늪(전체 중독).

### 핏빛성채 — 언데드 (공포·저주·소환)

- **데드맨** · 앞줄(무등급) — 패시브 [기존] *썩은 몸*(출혈·독 면역). 빨강 물어뜯기 · 파랑 [수정] 붙잡기: 속박 + **붙잡은 동안 자신 받는 피해 −20%**.
- **병사 데드맨** · 앞줄(무등급) — 패시브 공유. 빨강 녹슨 베기 · 파랑 [새] **방패 들기: 아군 하나 대신 맞기 2차례**(`cover`).
- **지휘관 데드맨** · 지원(무등급) — 패시브 [수정] *썩은 지휘*: **데드맨 계열 소환수·아군 근력 +15%**. 빨강 [기존] 진군 명령(아군 피해 +20%) · 파랑 내리찍기.
- **스컬 랫** · 유틸(무등급) — 패시브 [기존] *쥐떼*(먼저 움직임). 빨강 갉기 · 파랑 [수정] 숨기 → **숨고 다음 차례 게이지 +30**(`gauge`).
- **벤시** · 방해(원딜) — 패시브 [수정] *원령*: 물리 −10% → **공포 대상이 행동을 건너뛸 확률 +15%p**.
  빨강 [기존] 비명(어둠 + 공포) · 파랑 [수정] 흐느낌: 적 전원 정신력 −15% + **영혼력 재생 정지**.
- **스켈레톤 메이지** · 원딜/지원 — 패시브 공유 *갈비뼈 속 핵*.
  빨강 [기존] 그림자 화살 · 파랑 [기존] 뼈 방벽(아군 물리내성) · 초록 [수정] 저주 속삭임: 항마력 −20% + **저주 대상 받는 마법 피해 +15%**.
- **스켈레톤 아처** · 원딜 — 패시브 공유.
  빨강 [기존] 뼈화살 · 파랑 [수정] 일제 사격 → **표식 화살: 대상에 표식(아군 전원 명중 +15·피해 +10%, 3차례)**.
- **가고일 석상** · 앞줄 — 패시브 [수정] *돌 피부*: 베기·찌르기↓ 둔기↑ + **방어 중이면 반격**(`counter`).
  잿빛 [기존] 악의 소리 · 빨강 [기존] 석화 · 파랑 [새] **석상 자세: 자신 석화(못 움직임) + 받는 피해 −70% + 끌어들이기 1차례**.
- **구울로드** · 소환사 — 패시브 [기존] *무리의 주인*(구울 계열 소환수 근력↑).
  빨강 [기존] 엘더 소환 · 파랑 [수정] 포식자의 손톱: 부패 + **소환수가 있으면 위력↑**.
- **데스핀드** · 앞줄/소환 — 패시브 [수정] *육체보존*: 재생 + **적을 쓰러뜨리면 출혈 해제·생명력 10%**(`on_kill`).
  잿빛 [기존] 망자의 부름 · 빨강 [기존] 반월 베기(출혈) · 파랑 [수정] 방패팔 막기 → **자신 대신 아군 하나를 지킨다(`cover`) + 물리 −50%**.
- **키메라 울프** · 근딜 — 패시브 [수정] *여러 개의 머리*: 기본 공격 추가타 → **출혈 대상이면 추가타 확정**.
  빨강 [기존] 삼중 물기 · 파랑 [기존] 광폭 돌진.
- **본 나이트** · 앞줄(색 = 타입) — 패시브 [기존] *방부제*.
