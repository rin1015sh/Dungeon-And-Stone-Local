# 1층·균열이 텅 빈 느낌 — 원인과 제안 (2026-10-21)

> 사용자 피드백(2026-10-21): "1층이랑 균열이 너무 텅 비고 재미없다. 몬스터 수도 너무 적다. 피어 앤 헝거는 잡템 얻기로 지루함을 없앴는데 DAS는 원작 특성상 잡템이 애매하다."
> **적용(2026-10-21, 사용자 "abcdf 하고 싶은데 1층에도 약탈자가 있음")**: A·B·C·D·F를 넣었다(E 균열은 하지 않음) — 정한 값과 바꾼 점은 ASSUMPTIONS EX1~EX12, 지금 모습은 CANON §4. 아래는 처음 제안 그대로 둔다.

## 0. 지금 수치 (데이터에서 잰 것)

| 항목 | 값 |
|---|---|
| 1층 걸을 수 있는 칸 | 약 63,000칸 |
| 무리 | 지역 5곳 × 20~26 = 약 115무리(무리당 1~3마리 → 약 230마리), 하루마다 늘어 최대 +18 |
| 무리 하나당 바닥 | 약 550칸 |
| 지역 몬스터 | **팔마다 한 종뿐**(동 칼날늑대 · 서 노움 · 남 구울 · 북 고블린), 중심만 4종 섞임 |
| 기념비 → 포탈 최단 | 약 350칸 = 게임 7시간 = **실제 약 70초** |
| 그 길 6칸 안의 동굴 요소 | 8~13곳(일부는 글만 나오는 분위기 요소) |
| 처치 보상 | 경험치 = **종별 첫 처치만** · 9등급 마석 1개(20스톤) · 정수 2% |
| 물가 | 식량 300 · 하급 포션 20,000 · 횃불 10,000 스톤 |

## 1. 원인 — "수가 적다"보다 "싸울 이유·볼 것이 같다"

1. **두 번째 전투부터 보상이 거의 0이다.** 경험치는 종별 첫 처치뿐(원작 규칙)이고, 1층은 4종이다. 그다음은 20스톤짜리 마석 하나와 2% 정수뿐 — 식량 하나에 15마리, 포션 하나에 1,000마리다. 피어 앤 헝거의 잡템이 하던 일(전투·뒤지기마다 작은 보상)을 하는 것이 DAS에 없다.
2. **팔 하나 = 몬스터 한 종.** 동쪽 팔은 끝까지 칼날늑대 1~2마리만 나온다. 수를 늘려도 같은 전투가 반복될 뿐이다.
3. **세계가 멈춰 있다.** 168시간 동안 지도에서 바뀌는 것은 무리 수 증가뿐이다. 원작의 1층은 신참 탐험가로 붐비는 곳인데, 지금 게임에서 다른 탐험가는 미리 놓인 시체로만 나온다.
4. **고르게 퍼져 있다.** 밀도가 고르니 "위험한 곳 / 쉬는 곳"의 리듬이 없다.

## 2. 원칙 — 원작에 맞는 '잡템'은 무엇인가

원작 규칙(PROMPT §4.3 요약): 몬스터는 죽으면 빛 먼지가 되어 **장비도 함께 사라지고 마석·정수만 남는다**. 부산물·시신은 '왜곡' 없이 못 가지고 나간다. **마석과 '아이템 취급' 물품은 가지고 나갈 수 있다.** 몬스터는 탐험가의 시신에 관심이 없다.

→ 몬스터에게서 잡템을 다시 떨어뜨리지 않는다(2026-10-21 결정 G2a 유지). 대신 **물건은 사람에게서 나온다** — 죽은 탐험가의 유품, 살아 있는 탐험가와의 거래·약탈. 몬스터가 주는 것은 마석과 정수, 그리고 **정보**(도감·약점)다.

## 3. 제안 (추천 순)

### A. 탐험가 유품 — DAS식 잡템 (추천 1순위)

지금 `explorer_corpse`는 정해진 자리의 정적인 상자다. 이것을 1층 루팅의 중심으로 키운다.

- **시체가 생긴다**: 168시간 동안 신참 파티가 실제로 죽는다. 무리가 짙은 곳·암흑지대 근처에 시간마다 확률로 새 시체가 생기고, 그 직전에 멀리서 **비명·싸움 소리**(소리 방향만, 글 없음 — UI19)가 난다. 늦게 갈수록 구울이 먼저 와 있다(`ghoul_feast`와 이어짐).
- **유품 = 그 사람이 들고 온 것**: 마석 주머니(마석 여러 개), 식량·횃불·포션, 낡은 장비(대장간에 팔 수 있다), **신원패**(`explorer_tag` — 도시에서 반납하면 보상, 나중에 명성과 이을 자리). 시체마다 "누구였는지"가 유품으로 보인다(창술사 시체 = 창·가죽 갑옷).
- **가방 격자 10×6이 고민을 만든다**: 무거운 갑옷을 들고 갈지, 식량을 챙길지 — 피어 앤 헝거의 "무엇을 버릴까"를 그대로 가져온다.
- 구현: 기존 동굴 요소 틀(`data/events`, `give`) + 시간 사건(새 시체 놓기)만 더하면 된다. 고정 지도 좌표는 건드리지 않는다(런타임에 빈 바닥 칸을 고른다).

### B. 살아 있는 탐험가 무리 (추천 2순위 — 원작 확인 필요)

지도 위를 돌아다니는 NPC 파티. 몬스터처럼 움직이지만 만나면 **선택 창**(ChoicePopup)이 뜬다.

| 종류 | 만나면 |
|---|---|
| 신참 파티 | 거래(마석 ↔ 식량·횃불), 소문 하나(균열·히든 피스 자리), 그냥 지나침 |
| 부상자 | 포션을 주면 신원패·마석으로 갚는다 / 두고 가면 나중에 시체 |
| 싸우는 중인 파티 | 끼어들면 함께 전투 — 드롭 다툼(명세 V2 §8) |
| 약탈자 | 기습 전투(사람 적). 이기면 그들의 유품 전부 |
| 함께 머물 파티 | 3일 차 이후 5인이 모이는 조건 → **드레드피어 소환**을 혼자서도 노릴 수 있다 |

- 원작 PROMPT §4.3에 "약탈자·배신" 훅이 있다. 다만 **1층에서 다른 탐험가가 어떻게 그려지는지는 원작 원문이 필요하다**(아래 §5).
- 사람 적의 전투 그림(정면)은 새로 그려야 한다(아군 뒷모습 몸 그림을 바탕으로).

### C. 전투 한 번의 값 올리기 (수치만 — 바로 할 수 있다)

- **정수 기대감**: 9등급 2%로는 한 원정(20~40마리)에 정수 0.4~0.8개다. 원작 드롭률(0.01%)은 이미 버렸으니(`drop_chance_original`), 1층 원정 한 번에 1~2개를 노리는 수준(4~5%)을 시험한다. 정수가 DAS의 진짜 '레어 드롭'이다.
- **마석의 쓸모**: 20스톤짜리 마석이 의미 있으려면 도시에서 그 돈으로 살 것이 있어야 한다. 식량 300·횃불 10,000·포션 20,000은 마석 수백 개라 원정 수입과 단위가 맞지 않는다 → `docs/balance/city.md` 물가를 "1층 원정 한 번 = 식량 몇 개 + 포션 하나" 수준으로 다시 맞춘다.
- **조사 = 수집**: 같은 종을 다시 잡을 때 할 일 — 전투 중 '조사'로 도감 칸(약점·저항·행동)을 하나씩 연다. 다 채운 종은 도시 도서관·길드에서 값을 받는다(정보의 가치). 경험치를 새로 만들지 않고 반복 전투에 목표를 준다.

### D. 밀도와 리듬

- **팔마다 섞기**: 팔의 주종 70% + 나머지 3종 30%(층 JSON `regions[].weights`만 바꾸면 된다). 무리 구성도 섞기(고블린 + 칼날늑대 같은 혼성 무리는 원작 확인 후).
- **수를 늘리되 뭉치게**: 지역당 20~26 → 30~40무리. 고르게 뿌리지 않고 소굴·고블린 모닥불·물가 둘레에 짙게, 굴 사이는 고요하게 — 위험한 곳과 숨 돌리는 곳이 번갈아 온다.
- **지도 위 행동 차이**(같은 종이라도 만날 때마다 다르게): 칼날늑대 = 냄새를 쫓아 뒤에서 따라옴(남은 일 A5 "칼날늑대 냄새"), 고블린 = 정해진 길을 순찰하고 밤에 모닥불에 모임, 구울 = 시체(A의 새 시체)로 모여듦, 노움 = 은닉처를 지킴(이미 있음).
- **잴 수 있게**: `tools/sim_walk.gd`(새 도구) — 기념비 → 포탈 4길과 무작위 걷기에서 "무언가(전투·요소·소리·탐험가)를 만나기까지 걸린 실제 초"의 분포를 낸다. 목표를 숫자로 정한다(예: 평균 15초, 최장 40초 이하).

### E. 균열

챕터마다 전투가 1~5번이고 그 사이는 걷기뿐이다.

- **곁방**: 챕터마다 본길에서 벗어난 방 1~2개 — 강한 무리 + 정수 확률↑, 또는 함정 + 보급, 또는 히든 피스 단서. 들어갈지 말지가 선택이 된다.
- **먼저 들어갔다 죽은 파티**: 균열 안 탐험가 시체(A와 같은 틀) — 그들이 어디서 왜 죽었는지가 다음 위험의 예고가 된다(장면 묘사는 괜찮다 — 부연설명이 아님).
- **현지 물자**: 균열마다 그 안에서만 쓰는 물건 — 빙하굴 땔감(추위), 녹색 탄광 폭약·지지목(이미 `mine_explosive`), 강철의 묘 해체 도구(함정), 핏빛성채 성수(데드맨). '가지고 나가는 잡템'이 아니라 '여기서 쓰는 물자'라 원작 규칙과 부딪히지 않는다.
- **균열 정수율**: 원작은 "균열은 정수 드롭률이 높다". 균열 일반 몬스터의 정수율을 필드의 2배 정도로 — 균열 전투마다 기대감.

### F. 시간에 따라 바뀌는 1층

1일 차 신참이 많다 → 3일 차 시체가 늘고 구울이 많아진다, 드레드피어 소환 가능 → 마지막 날 약탈자가 늘고 포탈 근처가 붐빈다. "지금 어디로 갈까"에 이유가 생긴다(A·B가 있어야 의미가 있다).

## 4. 하지 않을 것

- 몬스터 잡템 되살리기(G2a, 2026-10-21 결정).
- 지도를 바꾸는 요소·벽 표식·쪽지 지도·수정 맥(FE에서 하지 않기로 함).
- 화면에 규칙을 풀어 쓰는 문구(부연설명 금지·UI19) — 유품·탐험가 무리도 그림·소리·선택지로만.

## 5. 결정이 필요한 것

1. **어디부터**: 추천 = **C(수치) → D(섞기·뭉치기 + sim_walk) → A(유품)** 순서. 셋 다 원작 원문 없이 할 수 있다. B·F는 원작 확인 뒤.
2. **원작 원문 요청**: 1층(수정동굴)에서 다른 탐험가 파티를 만나는 장면, 약탈자가 1층에서 활동하는지, 신원패를 길드에 반납하는 규칙이 있는지.
3. **물가 재조정**(C): 식량·포션·횃불 가격을 원정 수입에 맞출지, 아니면 원정 수입(마석 값)을 올릴지.
4. **혼성 무리**(D): 서로 다른 종이 한 무리로 나와도 되는지.
