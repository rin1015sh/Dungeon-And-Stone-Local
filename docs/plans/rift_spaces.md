# 균열 공간 설계 (A5 — 2026-10-18 구현됨)

> **2026-10-20 바뀜(RF16)**: 챕터 사이 길목(출구·2챕터부터 입구)을 모두 지도 가장자리로 옮겼고, 필요한 곳은 3칸 굴을 뚫었다(앞 챕터 출구와 다음 입구는 반대쪽). 녹색 탄광 4챕터는 지도를 위아래로 뒤집었다. 아래 배치도 그림(`rift_boards/`)은 그 전 것이라 출구·입구 자리가 다르다 — 정본은 `data/maps/rifts/` 설계도.

사용자 지시(2026-10-18): 지금 균열은 네모 방을 이은 큐브 던전이라 지루하다 → 벽 대신 울타리·절벽 같은 경계, 화면이 꽉 차는 오픈월드 던전,
뒷배경, 요소로 꽉 찬 공간(핏빛성채 무기고·연회 테이블, 녹색 탄광 철로·광차 …). 그림 느낌은 사용자 첨부 4장(강철의 묘 · 녹색 탄광 · 빙하굴 · 핏빛성채 순).

- 설계도: `data/maps/rifts/<균열>_<챕터>.json` — 한 글자 = 한 칸(legend → 타일 id), marks = 시작·조우 자리(slots, 데이터 encounters 순서 — 수호자는 마지막)·출구·히든 피스(hidden 순서)·위험 묶음 가운데(hazards × count 순서).
- 배치도 그림: `docs/plans/rift_boards/<균열>_<챕터>.png` (빨강 = 조우, 노랑 = 히든 피스, 주황 = 함정, 초록 = 시작, 하늘 = 출구).
- 조우·히든 피스·함정·출구 조건은 데이터 그대로, 자리만 장면에 맞게. 시작에서 모든 조우·출구·함정에 걸어서 닿는지 검사했다.
- **아직 게임에 쓰지 않는다** — 다음 단계: 설계도 생성기(`rift_blueprint`) + 경계·소품 타일, 그다음 재질·소품 그림·뒷배경.

| 균열 | 챕터 | 공간 |
|---|---|---|
| 강철의 묘 | 1 함정 복도 | 빛줄기가 새는 무너진 입구 → 붉은 카펫 행렬 복도(기둥·깃발·금빛 촛대, 압력판·화살) → 남북 매장실(석관 줄) → 계단참 |
| | 2 회전 칼날의 방 | 대전당(거대 기둥 두 줄·떨어진 샹들리에·잔해 더미·꺼진 바닥과 쇠 난간) → 칼날 회랑 → 갑옷 진열실 → 기사 석상의 전당 |
| | 3 수수께끼 문 앞 | 계단 → 석상·화로 진입로 → 양옆 경비실 → 거대한 강철 문과 문지기 |
| | 4 강철의 분묘 | 둥근 묘실, 기둥 고리, 단 위 거대 강철 관, 양옆 꺼진 바닥(난간), 보물 더미 |
| 녹색 탄광 | 1 일자 갱도 | 무너진 천장 → 철로·버팀목·랜턴·광차의 곧은 갱도 → 공구 창고·광석 투입구·광부 쉼터 → 끊긴 철로 벽 → 승강기 |
| | 2 무너진 다리 | 서쪽 작업장(오두막·승강기·기중기) → 심연 위 나무 가대교 / 북쪽 절벽 비계 길 → 고블린 야영지(화약통) |
| | 3 절벽의 원형 계단 | 수직갱 둘레를 감는 계단, 가운데 심연, 기중기·랜턴, 화약 창고, 바닥의 무너진 갱도 |
| | 4 무너진 공동 | 버려진 광산 야영지 → 거대 녹색 결정·버섯·슬라임 웅덩이가 있는 둥근 공동 |
| 빙하굴 | 1 문지기와 얼음 동굴 | 언 숲·언 호수·버려진 탐사대 야영지 → 고드름 아치(예티) → 길잡이 기둥이 선 얼음 동굴, 늑대 굴 |
| | 2 얼음 계단과 토템 | 높은 턱 → 얼음 계단 → 토템 분지, 길잡이 기둥 고리(하나 금 감), 얇은 얼음벽 |
| | 3 지하수맥 | 폭포 웅덩이 → 지하 강 양쪽 둑(얼어붙은 여울로 건넘) → 급경사 → 로프로 건너는 낭떠러지 → 얼음 속 오크 공동 |
| | 4 얼음 가루 공동 | 언 폭포, 고드름 숲에 둘러싸인 거대 공동 |
| 핏빛성채 | 1 외곽 검문소 | 붉은 안개 위 고원: 버려진 행렬 → 옛 전장 → 가시 방책 초소 → 말뚝 울타리 진지(무기고) → 외성 관문 |
| | 2 도개교 | 교두보(공성 잔해·쓰러진 기사들) ↔ 핏물 해자 ↔ 흑빛 성벽 |
| | 3 외성벽 시가지 | 집·골목·무너진 집·대장간·선술집 → 마른 분수대 광장·좌판 → 내성문 |
| | 4 내성벽 지하 감옥 | 계단참 → 경비실 → 쇠창살 감방 복도 → 고문실 → 하수로 → 납골당 → 시체 구덩이 |
| | 5 영주성 악마 숭배실 | 'ㅁ'자 회랑(안뜰) — 무기고·서고·연회장 → 거대 기둥·스테인드글라스·피의 균열 바닥의 숭배실 |
