# 던전 앤 스톤 (Godot 4 팬 프로젝트)

소설 『게임 속 바바리안으로 살아남기』의 작중 게임 「던전 앤 스톤」을 구현하는 **비상업 팬 프로젝트**입니다.
2D 3/4 쿼터뷰 던전 크롤러 + 민첩 기반 턴제 전투 + 하드코어 로그라이크 RPG.

- 엔진: **Godot 4.7** (GDScript, GL Compatibility 렌더러)
- 현재 단계: **M1 탐험** (1층 수정동굴 탐험까지) — 진행 상황은 [docs/PROGRESS.md](docs/PROGRESS.md), 설계는 [docs/DESIGN.md](docs/DESIGN.md)

## 실행

1. Godot 4.7로 이 폴더(`project.godot`가 있는 곳)를 연다.
2. F5(프로젝트 실행).

명령줄:

```bash
godot --path .
```

## 검증

```bash
GODOT=/path/to/godot bash tools/check.sh
```

데이터 검증 → 단위 테스트 → UI 스모크 → 메인 씬 스모크를 차례로 돌리고 "모든 검증 통과"를 출력하면 정상입니다.

## 콘텐츠 추가

콘텐츠는 `data/` 아래 JSON만 편집해서 추가합니다(코드 수정 없이). 각 폴더의 `_template.json`이 형식 예시입니다.
추가한 뒤 `godot --headless --path . --script res://tools/validate_data.gd`로 참조 오류를 확인하세요.

## 한글 폰트

Noto Sans KR Regular(SIL OFL 1.1, `assets/fonts/OFL.txt`)를 번들했습니다. 다른 OFL 한글 폰트를 쓰려면 `assets/fonts/`에 넣고 `data/render.json`의 `font.path`를 바꾸세요.

## 테스트 플레이 체크리스트

### M1 — 1층 탐험

| # | 하는 것 | 보여야 하는 것 |
|---|---|---|
| 1 | 타이틀에서 **새 탐험가** | 이름·종족·시작 템플릿·타고난 몸(스탯)·자원·가진 것(횃불 2, 마른 식량 3) 화면 |
| 2 | 이름을 쓰고 종족/템플릿을 바꾸거나 **다시 굴리기** | 스탯이 다시 굴려지고 리롤 횟수가 준다(종족·템플릿을 바꾸면 3회로 돌아옴) |
| 3 | **미궁으로 들어간다** | 1층 수정동굴의 무작위 위치. 비스듬히 내려다보는 시점: 벽은 어두운 윗면 + 돌 줄눈이 있는 앞면, 일부 벽은 보랏빛 수정으로 빛남. 기록창에 입장 문구 |
| 4 | **WASD / 방향키**로 이동(누르고 있으면 계속) | 한 칸씩 이동, 좌상단 시각이 조금씩 흐름(민첩이 높을수록 덜 흐름). 벽에 막히면 시간이 흐르지 않음 |
| 5 | 벽 바로 북쪽에 서기 | 캐릭터 다리가 벽 윗면에 가려지고, 가려진 부분은 푸른 반투명 실루엣으로 보임 |
| 6 | 돌아다니기 | 지나온 곳은 어둡고 차가운 색으로 기억(안개), 처음 가는 곳은 검다. 랜드마크·포탈을 처음 보면 기록에 "발견" |
| 7 | 어두운 곳(암흑지대)에 들어가기 | "수정 빛이 닿지 않는 곳" 기록, 시야가 1m로 줄어듦 |
| 8 | **T** (횃불) | 횃불에 불이 붙고 따뜻한 빛, 손에 불꽃. 좌상단 "횃불 (남은 72시간) · 시야 7.0m". 다시 T를 눌러도 새로 켜지지 않음 |
| 9 | **Space**(1시간 대기) 여러 번 → 허기 30% 이하 | "[허기] 상태" 기록, 상태 줄에 허기, 근력·민첩 소폭 하락 |
| 10 | **E** (식사) | 허기 +40, 마른 식량 1개 감소. 배부르면 먹지 않음 |
| 11 | 기념비 근처로 가서 **Z** (휴식 8시간) | "기념비 곁에서 8시간을 잤다", 생명력·영혼력 회복. 안전지대 밖에서는 회복 없음 |
| 12 | 포탈/기념비 옆에서 **F** (살피기) | 포탈: "아직 그 너머로 갈 준비가 되지 않았다(2층은 M6)", 기념비: 안전하다는 문구 |
| 13 | **F1** (디버그) | 오른쪽 위 디버그 패널: 시간 스킵·폐쇄 직전·안개 걷기·이동·스탯·무적·시드 재생성 |
| 14 | 디버그 **폐쇄 1시간 전** → **+1시간** | 폐쇄 경고 후 "층이 닫힌다", 잠시 뒤 **강제 귀환** 결과 화면 → 타이틀로 |
| 15 | 새 탐험가로 들어가 디버그 **허기 0** → **+12시간** 여러 번 | [아사] 상태로 생명력이 줄다가 **죽었다.** 화면(사인: 아사) |
| 16 | 디버그 시드 칸에 숫자 → **다시 생성** | 같은 숫자면 같은 지형이 나옴 |

### M0 — 기반 점검

| # | 하는 것 | 보여야 하는 것 |
|---|---|---|
| 1 | 실행(F5) | 어두운 타이틀 화면에 "던전 앤 스톤", 한글이 깨지지 않음. 메뉴: 새 탐험가 · 기반 점검 · 종료 |
| 2 | **기반 점검** 클릭 | 왼쪽 탐험가·핵심 스탯, 가운데 자원·조작, 오른쪽 기록창. 기록창에 시작 문구와 "인간 전사. 타고난 몸을 확인했다." |
| 3 | 종족을 **바바리안**으로 변경 | 근력·물리내성이 오르고 정신력이 낮게 굴려짐. 생명력 최대치도 함께 바뀜 |
| 4 | **다시 굴리기** 3번 | 매번 스탯이 바뀌고 남은 횟수가 줄다가 0이면 버튼이 꺼짐 |
| 5 | **레벨 +1** 여러 번 | 영혼력 최대치가 Lv5까지 +10씩, Lv6부터 +30씩 오름(현재값은 그대로) |
| 6 | **근력의 비약** | 근력 최종값이 +10(초록색), 생명력 최대치도 오름. 버튼이 "비약 효과 지우기 (남은 3시간)"으로 바뀜 |
| 7 | **1시간 경과** 3번 | 남은 시간이 줄다가 "근력의 비약 기운이 빠져나갔다." 근력이 원래대로 |
| 8 | 허기 게이지 확인 | 도시(기본)에서는 허기 게이지가 안 보이고, 1시간 경과 시 "도시에서는 허기가 줄지 않는다" |
| 9 | **미궁 안에 있다** 켜기 → **1시간 경과** 70번가량 | 허기 게이지가 보이고 줄어듦. 30% 이하에서 "[허기] 상태가 되었다." + 근력·민첩 소폭 하락(빨간색) |
| 10 | **식사** | 허기가 차오르고 30%를 넘으면 "[허기] 상태에서 벗어났다." |
| 11 | **영혼력 5 소모** 연타 | 바닥나면 "영혼력이(가) 바닥났다." + "[영혼탈진]", 이후 "영혼력이 모자란다." |
| 12 | **1턴 경과** 몇 번 | 영혼력이 조금씩 차오르며 "[영혼탈진] 상태에서 벗어났다." |
| 13 | **피해 10** 연타 | 생명력이 줄고 0이 되면 "생명력이 다했다…"(M0에서는 기록만) |
| 14 | **완전 회복** | 모든 게이지가 가득 참 |
| 15 | 오른쪽 아래 **불러온 데이터** | 컬렉션별 항목 수와 "검증 통과 · 경고 2건" |
| 16 | **돌아가기** → **종료** | 타이틀로 돌아오고, 종료하면 창이 닫힘 |
