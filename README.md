# 던전 앤 스톤 (Godot 4 팬 프로젝트)

소설 『게임 속 바바리안으로 살아남기』의 작중 게임 「던전 앤 스톤」을 구현하는 **비상업 팬 프로젝트**입니다.
2D 3/4 쿼터뷰 던전 크롤러 + 민첩 기반 턴제 전투 + 하드코어 로그라이크 RPG.

- 엔진: **Godot 4.7** (GDScript, GL Compatibility 렌더러)
- 현재 단계: **M1 탐험** (1층 수정동굴 탐험까지) — 진행 상황은 [docs/PROGRESS.md](docs/PROGRESS.md), 설계는 [docs/DESIGN.md](docs/DESIGN.md)

## 실행

1. Godot 4.7로 이 폴더(`project.godot`가 있는 곳)를 연다.
2. F5(프로젝트 실행).

명령줄:

```bash
godot --path .
```

## 검증

```bash
GODOT=/path/to/godot bash tools/check.sh
```

데이터 검증 → 단위 테스트 → UI 스모크 → 메인 씬 스모크를 차례로 돌리고 "모든 검증 통과"를 출력하면 정상입니다.

## 콘텐츠 추가

콘텐츠는 `data/` 아래 JSON만 편집해서 추가합니다(코드 수정 없이). 각 폴더의 `_template.json`이 형식 예시입니다.
추가한 뒤 `godot --headless --path . --script res://tools/validate_data.gd`로 참조 오류를 확인하세요.

## 한글 폰트

Noto Sans KR Regular(SIL OFL 1.1, `assets/fonts/OFL.txt`)를 번들했습니다. 다른 OFL 한글 폰트를 쓰려면 `assets/fonts/`에 넣고 `data/render.json`의 `font.path`를 바꾸세요.

### 플레이 감사 수정 (2026-10-14)

- [ ] 도감(B): 목록과 설명이 창 안에서 스크롤되고, 창이 화면 밖으로 늘어나지 않는다
- [ ] 캐릭터(C): 왼쪽 = 요약, 오른쪽 탭 = 정수(흡수 대기가 맨 위, 남은 시간·흡수 버튼·못 하는 이유) / 세부 능력(세부 스탯·영구 강화·패시브·걸린 상태, 효과 없는 스탯은 *)
- [ ] 정수가 떨어진 뒤 HUD에 "흡수를 기다리는 정수 n개 — 남은 x시간"이 보이고, 대기(Space)·휴식(Z)을 누르면 한 번 경고한다(바로 한 번 더 누르면 그대로 한다)
- [ ] 소지품(I): 가방의 아이템을 [버리기]에 끌어 놓으면 버려진다. 가방이 차서 장착·벗기가 안 되면 기록에 이유가 나온다. 단축칸에는 쓸 수 있는 물건만 올라간다
- [ ] 생명력이 가득할 때 포션을 쓰면 "이미 가득하다"만 나오고 포션이 남는다(전투에서는 차례도 그대로)
- [ ] Escape → 일시정지 메뉴 [계속] [탐험 포기](두 번 눌러 확정 → 결과 화면). 정지 중에는 하단 바·단축칸 클릭이 먹지 않는다
- [ ] 포탈·기념비 옆에 서면 HUD에 "F 살피기 — 대상"이 나온다. 균열 안내문의 살피기 키가 F로 나온다
- [ ] 새 탐험을 두 번 시작하면 지도가 다르다. 균열 챕터를 오가도 기록이 이어진다
- [ ] 전투: 적이 6마리 넘게 늘어도 카드가 한 줄에 줄어들어 들어가고, 쓰러진 일반 몬스터 카드는 치워진다. 증원된 적은 "고블린 D"처럼 글자가 이어진다. 대상을 고를 때 커서가 놓인 카드가 금색으로 빛난다
- [ ] 전투: 중독·출혈 등으로 차례 시작에 생명력이 깎이면 기록에 나오고 숫자가 뜬다. 상태에 중첩(×2)·보호막 양이 보이고, 마우스를 올리면 설명이 나온다
- [ ] 승리하면 결과 칸에 이번 전투로 얻은 공적·전리품·정수가 나온다
- [ ] 균열: 원정마다 균열이 열린다. 가방이 가득해도 뿔피리는 "손에 쥐었다"로 남아 출구를 지날 수 있다
- 화면 캡처: `--combat --summon=4 --ally_summon --keys=menu_confirm`, `--combat --win`, `--essence --many --character`, `--bestiary --loot`, `--pause`

### 전투 행동창 — 고정 칸 선택판 (2026-10-14)

- [ ] 전투에서 행동창이 2열 × 3줄 고정 칸으로 나온다: 공격 · 스킬 / 방어 · 아이템 / 도주 · (빈 칸). 빈 칸도 테두리가 보인다
- [ ] W/A/S/D(방향키도)로 금색 테두리 커서가 움직이고, Space로 확정, Enter로 한 단계 뒤로 간다. 뒤로 가면 들어갔던 칸에 커서가 있다
- [ ] 정수를 여러 개 흡수하면 스킬이 6개씩 쪽으로 나뉘고 오른쪽 위에 "◀ 1/4 ▶"가 보인다. 오른쪽 열에서 D를 한 번 더 누르면 다음 쪽, 왼쪽 열에서 A면 이전 쪽(마우스로 ◀ ▶를 눌러도 된다)
- [ ] 칸 오른쪽 아래에 영혼력 대가, 재사용 대기("n차례 대기")·"대가 부족"·"봉인", 도주 성공 %, 대상 생명력 %가 작게 나온다
- [ ] 판 아래 설명줄에 커서가 놓인 선택지의 설명이 나온다(정수 스킬: 대상 · 피해 유형 · 거는 상태 · 재사용). 못 쓰는 스킬은 이유가 노란색으로 나오고 Space를 눌러도 쓰이지 않는다
- [ ] 마우스로 칸에 올리면 커서가 옮겨 가고, 누르면 확정된다
- [ ] 확률 상태 스킬(예: 마비 시선)이 안 걸리면 기록에 "…아무 효과도 내지 못했다"가 나온다
- 화면 캡처: `--screen=explore --essence --many --combat --skills --keys=menu_right,menu_right` (`--drain`: 영혼력 0)

| 7 | 아이템 **오른쪽 클릭** | 장비는 장착, 포션·식량·횃불은 사용 |
